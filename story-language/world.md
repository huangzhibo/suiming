# World、Place 与 Resource

## World

`world/core.md` 与 `world/<id>.md` 都是无 frontmatter 的普通 Markdown；标题只是 Markdown 主体的一部分。

`world/core.md` 只放同时满足以下条件的少量公理：

- 已是本作确定事实，而非研究材料、作者愿望或主题宣言；
- 在全书范围稳定成立，改变它会重解释大量 StoryBeat；
- 大多数局部任务不读取它就可能误判故事。

写规则及其限制、代价、例外或可观察后果，不把 `core` 写成全书世界百科。例如：

```markdown
# 斗气世界

修炼境界可以被公开测量，并形成真实的实力差距；家族与宗门据此分配资源、身份和婚姻筹码。功法、斗技、丹药和机缘能够改变修炼速度与突破机会，因此也会持续引发交换和争夺。
```

局部适用或可独立修改的知识写入 `world/<id>.md`，并由每个依赖它的 Beat 把本地 id 写入 `refs.world`。中文作品可以使用简洁稳定的中文本地 id；ASCII id 继续合法。id 必须适合作为单个文件名，不能含空白、`:`、`/`、`\\` 等路径保留字符。Markdown 主体应足以回答相关人物能遭遇什么规则、规则怎样起作用、边界在哪里；不要保存来源笔记、未采用候选、情节流水账或手写使用索引。例如 `world/斗气修炼.md` 可以只保存当前故事真正依赖的细化规则：

```markdown
# 斗之气阶段

修炼者成为斗者前，以斗之气段位衡量进展；达到九段后还要凝聚斗之气旋才能完成突破。聚气散可以提高这次凝聚的成功机会，所以对尚未成为斗者的年轻修炼者格外珍贵。
```

### 充分性与演化

World 的完整度以能否稳定产生、约束并解释当前故事为准，不以历史、地理、文化、制度、经济等固定分类是否填满为准。起始规模由实际输入决定：原创且输入稀疏时可以先建立最小基础；Source 改写、已有设定集或成熟世界观可以从较完整的 World 起步，以相关既有信息为基础并按当前 Intent 取舍。不要为了显得完整而建立空置目录，也不要为遵循流程主动扩写、压缩或按不同分类重复保存同一事实。

世界、人物、情节和结局必须共同成立。需要复用、独立引用、修改或审查的世界知识写入 World；只解释局部行动或结果、无需独立寻址的事实留在 StoryOutline。高影响规则应说明与其作用范围相称的执行、受益、承担、规避和后果，不能只为当前桥段制造例外。

World 描述组织、制度、信仰、共同体和秩序在本作中如何运作，不替代它们在故事里的形成与作用过程。其起源、扩张、取得信任、遭遇抵抗或异化若改变人物选择、因果结果或后文理解，仍由 StoryBeat 承载；若故事开始前已经成熟，只需保存当前情节实际依赖的历史压力。是否展示生成过程由作品决定，不按百科目录强制补史。

让 Writer 写正文之前，关键人物命运、冲突、胜负、转折和结局都应得到当前 World 支持，Writer 不应再发明改变因果的世界事实。作品可以保留谜团，但不能把尚未设计的缺口伪装成谜团。

## Place 与 Resource

需要稳定寻址、跨 Beat 连续性、独立审查、硬状态或后续回收的地点与线性资源，分别保存在 `world/places/<id>.md` 与 `world/resources/<id>.md`。路径提供 kind 和本地 id；frontmatter 只保存可选的寻址信息，以及开场已经成立且需要确定性重放的稀疏 `initial`。

例如 `world/places/萧家迎客大厅.md`：

```markdown
萧家用来接待正式来客的大厅，族长、长老和宾客都能见证其中的交涉。在这里处理婚约，原本属于两人的选择会同时成为家族名誉和权力关系的公开事件。
```

Resource identity 只保存会跨 Beat 转移、回收或接受硬状态检查的特定对象。例如 `world/resources/净莲妖火残图·海波东藏图.md`：

```markdown
---
initial:
  holder: 海波东
---
海波东收藏的净莲妖火残图。边缘纹路能与萧炎已有残片相接，因而可与其它同源残图区分；它本身不能直接提供力量，价值来自继续拼合和寻找净莲妖火的线索。
```

`initial` 只给出故事开场状态，不随情节更新。谁带来、拒收、取得或消耗它，仍写在 StoryBeat 中；需要后续确定性追踪的结果写入该 Beat 的 `changes`。

- Place：写稳定空间特征、进入与使用条件、能提供的机会和限制，以及人物会怎样感知它；毁坏、封锁或控制权变化写 StoryBeat，必要时投影状态。
- Resource：写稳定功能、识别方式、边界、稀缺性和不可替代性；取得、转移、消耗或毁坏写 StoryBeat，必要时投影状态。聚气散等可重复生产的类别知识属于 World，不为每次普通出现建立 Resource。

`name` 与文件 id 相同时可省略，不同时用于显示名；`aliases` 与 `initial` 可省略，Markdown 主体不能为空。一次性场所或普通物件直接写进 StoryBeat。人物及家族事实使用独立的 [Character](character.md) 模块。
