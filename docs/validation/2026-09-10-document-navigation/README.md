# 统一文档入口验收

日期：2026-09-10。

## 结论

Beat 的作品页与源文件页原本使用同一份内容、草稿和编辑器，独立页面入口没有增加编辑能力。现统一为同一个情节页面，保留「设计 / 正文」内容选择及「阅读 / 编辑」切换；编辑继续使用现有 Markdown / YAML 编辑器，不是 Live Preview。

文件树点击设计或正文文档时准确选择对应内容，普通打开复用当前窗格中已有页面；编辑中同步切换实际保存目标，两份草稿分别保留。菜单移除「查看源文件 / 查看对应作品对象」，保留定位文件、复制路径、Finder、分屏与版本操作。搜索不再重复列出同一作品文档的对象与文件入口。

旧文件标签、访问历史及最近访问统一页面身份，保留标签 ID、分屏、草稿和编辑位置，不擅自关闭已有副本。索引和配置等 YAML 文件继续使用文件查看器保留缩进；辅助文件、未知路径与索引无法建立时保留通用文件入口。已识别文档的格式诊断和编辑修复能力仍可用。
