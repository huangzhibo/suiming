# 文档外壳与状态反馈验收（2026-10-16）

## 范围与隔离

按作者截图审查标签、文档导航、编辑操作、异常反馈和底部状态栏的职责。沿用人物、情节、期待、审稿、版本比较等内容组织，只收敛公共外壳。决定见 [ADR-0032](../../adr/0032-document-shell-feedback.md)。

真实 Electron 通过 `launchDesktop` 启动，每条用例使用临时作品、独立 user-data、配置与凭据路径。作品来自仓库 fixture；未访问日常作品、日常凭据或真实模型服务，未修改 Canon 历史。未刷新作者正在编辑的日常窗口；隔离测试与日常应用分别对待。

## 发现与修正

1. **未保存状态插入第三行 header。** 新几何验收先失败：保存不在既有文档工具栏内。现在保存进入工具栏，未保存只在标签标记；读编切换保留草稿，放弃修改进入更多菜单并确认。
2. **同一文件异常重复提示。** 删除 / 冲突原来同时出现错误横幅与大卡片。现在当前文档只出现一个状态入口；外部变化不自动打开详情，尝试保存受阻才展开。删除恢复需要明确确认重新创建原路径，普通保存不重建文件。外部冲突先进入比较页，再设置合并基线，入口不在普通编辑页暴露可能覆盖外部内容的捷径。
3. **关闭确认框的失败残留。** 保存失败取消关闭后，错误曾残留为全局横幅。确认框只在框内呈现失败，取消时清理；文件异常仍由原文档入口承担。
4. **反馈占用内容空间。** 保存、复制、检查等结果回到底部状态栏，长消息可向上展开，检查详情保留直接入口。正文不再因反馈产生位移。格式诊断沿用文档状态入口，但仍保留保存修复后的文件的操作。
5. **详情聚焦与迟到结果。** 首轮完整桌面回归发现打开详情后转去对话，弹层后续聚焦可能拉回焦点；区分鼠标与键盘的初始聚焦，并在点击外部或焦点离开时取消回焦。Escape 返回原编辑位置；点击对话关闭详情尊重新的焦点；保存完成只在仍处于原文档、未切换焦点时回到编辑器。切页清理临时详情，异步失败不在另一份文档打开处理入口；冲突解除时清理展开状态，后续再次冲突不自动打开。
6. **底栏重复与过时状态。** 保存回执只说「已保存」，未提交状态由作品版本入口说明；继续输入立即移除已保存回执，避免与标签未保存标记矛盾。

## 验收路径

- 正常编辑：正文输入 → 标签未保存标记 → 工具栏保存 → 窄窗继续编辑。测量输入与保存前后编辑区起点不变、工具栏不溢出。
- 外部删除：人物、正文、辅助 Markdown 的草稿保留；普通保存只打开恢复详情，不写文件；Escape、切页返回、读编切换、重载、关闭失败取消与显式恢复均保留内容和焦点。辅助文件在 960 × 640 窗口验收，弹层边界不超出窗口。
- 外部重命名与恢复冲突：新旧路径独立；原路径重新出现后不覆盖外部内容；比较两方、调整草稿、设置基线再保存；对话输入不被后台变化抢焦点。
- 无草稿删除、首次正文和父设计删除：继续覆盖上轮的读取缓存、首次保存及真实编辑目标，不把未创建的正文误报为删除。
- 公共工作面：完整桌面套件覆盖检查结果入口、版本比较、人物与期待可视化、搜索 / 键盘、分屏、长正文与撤销、原生全屏及启动恢复。

主要回归在 `apps/desktop/test/external-files.test.ts`，已有桌面用例改用真实的新入口和标签未保存标记，不降低原来的数据、焦点或比较断言。
