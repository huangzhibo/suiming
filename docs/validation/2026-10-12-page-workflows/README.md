# 逐页工作流优化与复验（2026-10-12）

延续[上一轮](../2026-10-07-desktop-walkthrough/README.md)，本轮处理检查、审稿、故事状态与设置，并复查读者期待、地点、资源和秘密认知入口。决定见 [ADR-0017](../../adr/0017-check-review-state-workflows.md)。

## 环境与边界

生产 Electron 44，真实原生窗口；作品使用仓库 `examples/sanguo` 的隔离副本（231 情节）。配置、认证与作品均隔离，不读取真实作者凭据。宽窗 1460×940、窄窗 960×640，并复查左右分屏。截图为原生窗口直接保存，未修图。

审稿报告是人工构造的 12 条意见与长摘要，明确标注「仅验证布局与交互」，引用作品原句以验证段落定位。它不代表模型审稿结果，不作文学质量证据。本轮没有真实模型调用。

## 现场迭代

1. [第一版窄窗](images/07-review-narrow-restored.png)中，长意见将文件入口与单条复核挤进证据滚动区。最终把操作置于滚动区外，切换意见时回到证据开头；宽窗、窄窗与分屏重新检查，操作与稿件都可见。
2. [切换情节后](images/20-secret-state-audit.png)发现显式状态查询仍在旧位置，但位置选择器被隐藏。保留原来的跨页对照语义，仅在查询位置与当前情节一致时省略选择器；不一致时保留选择并提供「查看当前情节」。实际点击后位置与来源结果更新，阶段保持「结束后」。
3. 分屏后在左侧选择当前稿，右侧仍保留被审稿；重载后第 12 条意见和被审稿选择仍在。

## 验证

- 先补检查筛选的 Electron 验收，在旧 UI 上因缺少筛选控件失败，再实现。
- 桌面回归覆盖：437 条规模筛选与清除、筛选无结果、重载恢复；审稿长意见、窄窗操作几何位置、稿件切换、过期提示及重载；跨页状态位置、主体清除与引用；原有模型设置保存与认证流程。
- `npm run check` 通过；文档更新后链接检查再次通过。
- 工作台单元测试 66 / 66；状态文本回归 1 / 1；完整桌面 E2E 25 / 25，串行执行约 129 秒。
- 首次最终回归 24 / 25：新增状态断言同时匹配位置标题和来源链接，限定为位置段落后整套通过。另一次误以默认并发启动的测试已终止，不计入验收。
