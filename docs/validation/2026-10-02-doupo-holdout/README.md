# 斗破留出评测 r2（2026-10-02）

第一次用「忠实抽取 + 原作正文 + 续写对照原作」评估续写（作者 2026-10-02 定的评估方式，见[路线图](../../roadmap.md)第 6 节）。这次只是基线：Writer、prompt、评委协议都没改。

## 做法

- 作品 `doupo-holdout-2026-10-02`：Target Design 取自 [host 版忠实抽取](../2026-10-02-doupo-host/README.md)，beat-0001–0024 的正文直接放原作对应章节（转换规则同 host 记录），去掉 `source/`，免得 Agent 读到答案。
- 作者消息：「按设计写 beat-0025、beat-0026、beat-0027 的正文，接着前面的原作往下写，语气、节奏和人物说话方式与前文一致。写完检查并提交。」
- 模型：DeepSeek V4.1 Flash（`deepseek-flash`，思考 high）。一个 turn，24 次调用，估算 $0.17。
- 参照答案：原作里与这三节对应的章节，放在作品外的 `doupo-holdout-2026-10-02.reference/original/`。
- 两类信号，都不需要人读全文：
  - [`compare.py`](compare.py) 的确定性指标；
  - 盲读评委 `suim rank <beat> --candidate agent.md original.md --rounds 2`，评委是 `deepseek-v4-pro`，与写的模型不同，两轮交换顺序。

- **没有背书。**模型可能背过斗破，但 13 字片段重合不到 0.2%，最长的原样重合 22 字，属于套话级别。
- **beat-0025 写短了**，只有原作的 0.59：原作这一节场面多，Agent 把几场戏压成了概述。另两节篇幅接近。
- **段落偏碎**：段落数多、平均段长短，对话占比在 0026 / 0027 偏低。节奏差别主要在这里。

评委名次（两轮，各轮里 1 = 胜）：

| | beat-0025 | beat-0026 | beat-0027 |
| --- | --- | --- | --- |
| 带章节标题 | 原作 [1, 2]，Agent [2, 1] | Agent [1, 1] | Agent [1, 1] |
| 去掉标题 | Agent [1, 2]，原作 [2, 1] | 原作 [1, 2]，Agent [2, 1] | Agent [1, 1] |

- **评委信号现在不可信。**两轮交换顺序后名次互换就是位置偏差，每次都选排在前面的那份；只有 beat-0027 在两种设置下都一致判 Agent 胜。
- **章节标题会泄露身份**：原作带「第 N 章」标题，Agent 的没有，第一组结果因此作废，改成去掉标题再比。
- 只跑两轮，一次位置偏差就能翻转结论。
