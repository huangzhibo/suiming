# 模型设置与对话选择验收

2026-09-10，在隔离作品、配置与 Electron 测试窗口中验证。未引入 UI 包或额外运行框架。

## 已实现

- 设置页优先展示默认对话模型、思考深度与连接；专用任务模型和原始参数按需展开。
- 输入框使用灰色模型与思考选择，模型可搜索，只列已连接服务商，选中项有灰色背景；无已实现思考映射的模型隐藏档位控件。
- 对话选择不会修改全局默认。草稿和发送重试保留选择，新对话使用默认配置；进行中改选不切断当前请求，停止后继续或下一次回复时应用。
- 根 Agent 使用持久化的实际模型绑定。普通恢复保持原绑定，明确改选后按需新建 Attempt；在换绑前中断后仍恢复已确认选择。未知请求须先核对，拒绝换绑时不会覆盖原配置。
- `profile.thinking` 保存原始档位，避免从有损 API 参数反推错误；绑定时生成并校验实际参数。环境替换模型或参数时不携带旧模型的思考配置。
- 保存全局默认不停止活动回复；控制器闲置后才更新配置。普通对话不再被未配置的专用角色阻止启动。
- 移除对话预算表单与默认 8M token / 5 USD 占位额度；显式 CLI / API / 评测预算、停止、重试和循环保护保留。已有 Run 的已保存额度不自动重写。
