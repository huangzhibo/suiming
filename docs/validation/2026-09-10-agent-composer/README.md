# Agent 原生对话交互验收

2026-09-10。依据[源码参考与实施边界](../../assistant-ui-reference-review.md)和[输入能力方案](../../agent-input-capabilities.md)，使用既有 React / shadcn / TanStack / typed IPC 自行实现，没有新增 assistant-ui 或其他运行时依赖。

## 已验收行为

- 发送前持久保存本次文字、引用及命令 ID；等待期间继续输入、重载、迟到回执和切换委托均不覆盖其他草稿。一次未知结果通过原命令 ID 确认，避免重复创建 Run；补充接收成功而续跑失败时，仅重试续跑。
- `＋` 与 `@` 共用中文作品搜索。引用未保存设计时携带实际工作草稿、基线 revision 和完整内容 SHA-256，不改变磁盘文件。多引用可预览、移除；引用预览保留原始换行。
- 本地 UTF-8 文本读取后实际进入 launch / steer 的文字输入。选择、拖放与粘贴文件共用链路；非法编码、二进制、PDF 和超量文件不能冒充读取成功。重载后未完成的本地读取可重新选择文件。附件移除、重新读取及草稿移到新 Run 后的迟到结果按身份核对。
- 中文 IME 确认候选词不会发送；Enter 换行，⌘ / Ctrl + Enter 发送。`@` 仅在光标位于开头或空白之后且没有输入法合成时触发。
- 复制完成后反馈成功；引用消息进入新输入，导出走 Electron 系统保存对话框，主进程写出 Markdown 文件。测试仅替换保存路径选择，实际保存链路和内容仍执行。
- 消息与连续动作按持久事件顺序展示，工具状态更新不改变原位置。排队补充和已送入执行上下文分别呈现；没有另建前端运行队列。连接只读重连，不启动或恢复模型；Run 失败不误报为连接失败。
- 向上阅读后停止跟随，输入框增高和后续内容增长不改变阅读位置；重载恢复位置，「回到最新」回到底部。内容增长用 DOM 尺寸变化模拟，不能代替真实模型的长时间流式性能验证。
