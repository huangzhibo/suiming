# 分栏调宽与窄栏导航验收

日期：2026-09-09。对应[导航优化方案](../../history/workbench-navigation-optimization.md)及[作者工作台设计](../../web-product-design.md)第 3.2 节。

本文保留首轮分栏验收。随后根据作者截图，菜单切换已改为实际空间测量，撤回下文的固定 280px 阈值；「顺序」更名为「大纲」并排首位。最新行为及截图见[导航收纳与默认大纲修正](../2026-09-09-navigation-fit/README.md)。

## 实现与实际行为

- 左栏默认 280px、范围 200–480px；右栏默认 320px、范围 260–560px。拖动与正文之间的分隔线调宽，顶部与内容区共享实际宽度。
- 左栏不足 280px 时，五个入口收纳为「当前图标＋名称＋下拉箭头」；菜单保留文件、顺序、身份、依据、搜索及选中项，搜索仍支持 ⌘/Ctrl K。收起左栏按钮独立存在。拉宽后恢复原快捷图标与 Tooltip。
- 分隔线有 8px 命中范围，悬停、聚焦与拖动时突出边界；鼠标或触控指针均使用 Pointer Events。键盘左右方向键移动分隔线，Home / End 调到最小 / 最大，Enter 或双击恢复默认。
- 宽度偏好按作品保存；窗口缩小只限制实际宽度，不覆盖偏好。普通主区至少保留 600px，两栏不能同时放下时优先最近主动打开的一侧，另一侧保留展开入口。手动收起的栏不会随窗口放大自动打开。
- 页面、面包屑、tab 历史与编辑缓冲不因调宽或选择导航模式而改变。Agent 展开继续使用原主工作面规则，退出后使用普通分栏宽度。

分隔器沿用故事轴已有的指针拖拽方式，并补充键盘、指针取消及窗口失焦清理。没有引入新的布局依赖或修改 Runtime。

## 顶部贯通与去除提示

作者指出拖动条高亮没有到顶，且不需要操作提示。原因是手柄挂在内容栏中，顶部从标题栏下方的 y=40px 才开始。现在标题栏和手柄共用高度变量，手柄的命中范围及高亮向上延伸到 y=0；左右栏均贯通窗口全高。移除手柄 Tooltip，保留变色、调整光标、可访问名称、宽度值和键盘描述。

1460×940 的真实作品副本已核对[修改前](../2026-09-09-hover-refinement/09-resizer-before.png)、[左栏修正后](../2026-09-09-hover-refinement/10-resizer-left-after.png)及[右栏修正后](../2026-09-09-hover-refinement/11-resizer-right-after.png)。两侧手柄实测 top=0、bottom=940，悬停后 Tooltip 数量为 0，renderer 无异常。

Electron 分栏场景重新通过：两侧在标题栏 y=12px 处实际拖拽均改变栏宽，窗口位置与尺寸不变；悬停和聚焦不出现 Tooltip。继续验证分栏上下边界、窄栏导航、窗口缩放、键盘、双击与草稿恢复。`check:web`、`check:types`、前端构建、相关 Biome、文档链接与 `git diff --check` 通过。
