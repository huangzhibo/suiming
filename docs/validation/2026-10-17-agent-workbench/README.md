# Agent 界面上下文与操作验收

## 范围

采用 [ADR-0037](../../adr/0037-agent-workbench-context.md)。当前页面与选区在发送时冻结；桌面根 Agent 可查询现场、打开与定位文件、展示差异。复用原导航、比较、草稿与临时请求传输，操作不保存文件或推进 Canon。

## 组合验证

- 纯函数与工具边界：冻结后切页不改原消息；不发送未选中全文；重复引文、缺失引文和越界行拒绝；私有路径、host 接入目录、越界与符号链接不通过界面绕过原文件权限。CLI 不声明界面工具。
- 隔离 Electron：真实输入与发送，经受控模型调用生产工具；定位第二行后继续输入保留，展示草稿与磁盘差异，切回及重载后草稿仍在，文件与 Canon 未改变。
- 迟到结果：截住导航读取回执，分别切页、重载和停止；放行后不得打开目标或丢弃原草稿。
- 原按需编辑同步回归：多文件范围、双向覆盖、迟到回执、重载、关窗后隐藏编辑器同步和删除恢复继续有效。

## 迭代发现

首次重载用例失败：窗口开始加载时只断开了文件同步通道，新界面请求仍可能在新 renderer ready 时重送。现已在同一窗口生命周期断开两类请求；界面操作返回未确认，禁止重放，文件同步保留原有可重接策略。

另发现定位成功时，输入框仍持有焦点，CodeMirror 原生选区不可见。现启用标准 `drawSelection`，不抢焦点也能看到定位；重复展示复用已有标签，展开对话时先恢复文档工作面。窄窗上下文使用输入区上方的轻量弹层，不增加页面横幅。

## 最终结果

- `npm run check` 通过。
- 最终 `npm test`：497 / 497，0 skip。
- 完整 Electron 回归：85 / 85，0 skip。最后的选区显示、标签复用与路径匹配调整后，定向重跑界面能力、按需编辑同步、差异比较、长正文和键盘连续操作：18 / 18，0 skip。
- [真实桌面脚本](probe.mts)：隔离样例、GPT-6.1 Sol / high，两轮对话、6 次模型调用，约 30.3 秒。先识别当前未保存文件与选区，打开另一文档并定位引文；再展示原草稿与磁盘的差异。4 次工具调用依次为 `context → open → context → diff`，没有写入或提交。继续输入、输入焦点、重载后的草稿及 Canon 均保留，renderer 未报告异常。具体数据见 [real-measurements.json](real-measurements.json)。
- Langfuse 的隔离环境收到 2 条 turn、6 条 model、4 条 workbench observation，全部为 DEFAULT 级别；父级关联正确，用量与本地 Session 的 42,437 token 对齐，内容采集关闭。只保存 [脱敏对账](observations-summary.json)，不保存输入输出。
- 实际截图已走查：[桌面差异展示](desktop.png)、[960 × 640 窄窗上下文预览](narrow-context.png)。弹层位于输入区上方，定位与差异共用原文档外壳。

受控模型证明工具与界面机制；两轮真实调用证明这组明确请求可以完成。长时间连续创作中模型选择展示时机的稳定性仍待验证。未承诺任意 GUI 操作、跨应用自动化或模型永不误判作者意图。
