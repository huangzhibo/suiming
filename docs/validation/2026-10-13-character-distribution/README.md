# 人物分布统一与密度适配（2026-10-13）

## 范围与决定

作者确认“统一信息结构和交互规则，按数据调整呈现密度”。去掉超过 8 条，或超过 4 条且跨卷才显示全书分布的门槛：有记录就提供紧凑分布，零记录明确说明而不画空图。单卷不提供跨卷导航，跨卷沿用右侧目录与窄窗吸顶选择器。具体经历、状态说明和关联文档继续直接可读。

全书坐标、卷宽、颜色语义、悬停预览和键盘定位保持一致。分布带从 32px 压到 28px，减少标题间距；普通记录按实际像素间距统一使用圆点或刻度，不因总条数增减模块。不新增领域数据或持久状态。

## 原生桌面走查与迭代

使用公开《三国演义》验收副本，共 231 个情节，没有修改作品或调用模型。宽窗 1460×940，窄窗 960×640。

1. **典满，普通单点**：[单点人物](images/01-single.jpg)。第 90 个情节仍处在全书相应位置，没有拉伸到分布带正中。完整经历和家族关系保持可见，不增加卷目录。
2. **丁原，两条相邻记录**：[首轮画面](images/02-sparse.jpg)发现死亡叉号遮住普通刻度。将混合的状态和普通标记在同一条带内上下错开，保持全书横坐标不变；[迭代后](images/03-sparse-fixed.jpg)两者可辨，具体死亡经历仍直接展示。
3. **刘范，仅一条死亡记录**：[状态单点](images/04-state-only.jpg)。没有人物引用也保留这条状态经历，分布带居中显示红色叉号及死亡图例，不增加普通记录图例。这不是零记录人物。
4. **刘备，103 条记录、7 条状态变化、9 卷**：[首轮密集图](images/05-dense-before.jpg)混用孤立圆点与细刻度，容易造成重要性暗示。改成同一分布带内普通记录统一画法，有紧邻记录时全部用细刻度；[迭代后](images/06-dense-fixed.jpg)保留秘密菱形、蓝色普通刻度、完整时间线和卷目录。
5. **窄窗**：[960×640](images/07-narrow.jpg)仍显示分布与图例，状态标记不遮住普通记录，跨卷目录收为选择器。结束后恢复宽窗与人物侧栏，当前作者窗口已加载更新后的 renderer。
