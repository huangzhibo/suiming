根据作者对刘备页的反馈，检查分布预览、横向空间和跨卷定位。保留原有语义色、形状、卷带和连续时间线，全部经历仍直接显示。使用公开《三国演义》验收副本，刘备 103 条经历、7 条状态变化、9 卷；丁原为少量记录边界。没有调用模型或修改作品。

## 走查与迭代

1. **宽窗阅读**：状态说明与情节标题在空间足够时并排，右侧用于常驻卷目录，显示同标尺的相关情节数量。阅读位置变化会更新当前卷。见[宽窗状态经历](images/01-wide.jpg)。
2. **返回概览**：目录上的向上入口回到全书分布，概览坐标仍按全书 231 个情节计算，没有拉伸成人物专属顺序。见[概览与目录](images/02-overview.jpg)。
3. **预览和定位**：分布带显示卷名、序号、完整情节标题、已有状态变化及操作说明。悬停指向最近的实际节点，点击定位；方向键与 Home / End 遍历，Enter / Space 定位并聚焦经历。见[键盘预览](images/03-tooltip.jpg)。E2E 还用鼠标命中第 173 个情节，核对“蔡氏谋害刘备”再点击检查焦点。

4. **窄窗跳卷**：目录收为单行选择器，跳到“新野求贤与江东进取”后，标题和选择器一致，内容未被吸顶栏遮住。见[窄窗定位](images/04-narrow-navigation.jpg)。
5. **少量记录与恢复窗口**：丁原的两条经历直接可见，死亡保持红色叉号，没有多余概览或目录。见[稀疏人物](images/05-sparse.jpg)。结束后恢复身份侧栏与刘备宽窗，新 renderer 已加载；见[最终宽窗](images/06-final-wide.jpg)。

首轮几何验收抓到窄窗末端图标越过容器 3 像素的问题。修订时为绘图区增加两端留白，同时更新命中坐标，避免只裁掉图标或让点击偏移。随后验收又抓到窄窗跳卷后选择器退回上一卷：阅读位置计算漏掉吸顶栏的上下留白。已修正定位线，并以选择器文字与实际卷标题一致作回归断言。另一条旧验收假定缩窗后左栏一定收起；收起右栏后该条件不成立，已改为先等待真实宽度和两帧布局，再按入口的实际可见性操作。
