## 补充：前两卷切换时目录位移

作者发现切换前两卷时右侧目录移动。回归实测首卷目录 y=131.086px，第二卷 y=127px，整块上移约 4px；x、宽度与高度没有变化。第一卷定位后目录仍处于正常布局起点，后续卷则触发 sticky。根因是卷标题 `scroll-mt-4` 留白 16px，而宽窗目录 `top-3` 吸顶间距只有 12px。

目录吸顶改为 `top-4`，与标题定位统一为 16px。新增第二卷 → 第一卷的两轮往返测试，要求目录 x / y 与首次定位相比误差不超过 1px，同时核对当前卷。原有窄窗标题避让、首尾定位及当前卷同步验收继续保留。

`npm run check` 与完整桌面 E2E 29 / 29 通过。当前桌面窗口已刷新并现场对比[第一卷定位](images/07-first-volume-stable.jpg)与[第二卷定位](images/08-second-volume-stable.jpg)，目录位置保持一致。本次未改领域逻辑，未重复运行工作台纯函数测试或真实模型回归。

## 补充：页底把目录向上推走（2026-10-13）

作者继续追问“吸底”边界。旧布局的 sticky 容器只包住经历，其他关联文档和 120px 页尾留白在容器外。滚动到页底，容器底边会把目录一起向上推。940px 高窗口的自动化实测从 y=131.086px 移到 y=121.086px；1460×640 原生窗口中，目录标题、返回概览和前几卷都移出视口，见[修复前页底](images/09-bottom-before.jpg)。这与此前首两卷的 4px 位移是两个不同问题。

调整为经历、其他关联文档和原有页尾留白共用滚动范围。关联文档仍在经历之后，右侧目录持续可用；窄窗仍是单行选择器。目录高度由实际文档窗格的可用高度决定，超长卷列表只在目录内部滚动，保留返回概览。没有使用全局 fixed 定位，没有补大块占位来强行把末卷标题推到顶部，也没有隐藏任何内容。
