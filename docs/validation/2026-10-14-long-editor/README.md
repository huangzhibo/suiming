# 长正文编辑与差异比较验收（2026-10-14）

本轮用隔离的 Electron 工作台验证长正文的输入、撤销、比较、切页与重载，不调用模型，也不修改真实作品。结论是桌面机制与合成负载证据，不是长篇文学质量验收。

## 负载与方法

- 约 1 万、10 万、100 万字符的单个 Markdown 正文。内容由编号段落和重复中文句子组成，带明确结尾；长度包含标点、数字与换行，不全是汉字。普通章节与极端单文件压力分开报告。
- 响应测量每个规模各启动一个隔离窗口，连续输入 5 次；记录操作发出至完成（输入 / 撤销等另等两次动画帧）的耗时。包含自动化、帧等待及本机调度，不能当成纯渲染 CPU 时间或稳定百分位。修复前一轮、修复中一轮、最终代码一轮，不据此宣称吞吐提升。
- 10 万 / 100 万正文的回归另外创建两个 Canon 版本：每隔 100 段插入「修订记录。」，候选末尾再补写一句，应分别显示 13 / 113 处差异。每次都核对完整草稿和最终磁盘文件；不能用 CodeMirror 仅渲染可视区的 DOM 文本替代全文核对。
- 新增回归位于 [long-editor.test.ts](../../../apps/desktop/test/long-editor.test.ts)，经统一 `launchDesktop` 隔离凭据、配置与工作区。运行方式：`node --import tsx --test apps/desktop/test/long-editor.test.ts`。设置 `SUIMING_UI_CAPTURE` 可导出实际窗口截图。

## 发现与迭代

1. **返回编辑页后无法撤销。** 三个规模都复现：内容仍在，撤销无效。原来标签切换会销毁编辑器，只有单栏 / 双栏转换局部保留历史。现在按作品、标签、文件保留临时编辑状态，关闭或切换作品释放；仅当正文一致才恢复历史。另一视图修改了正文时，不重放旧栈覆盖新内容。
2. **长文的离散修改被并成大块。** 最初仅检查“出现差异”和“还原后有变化”不足以发现问题；截图出现大量未改正文被整块着色。补精确差异数量和单块还原范围断言后复现。CodeMirror 默认扫描限制会粗化长范围比较，改为单栏 / 双栏共用 100ms 精细计算预算。预算在算法检查点生效，含粗化回退的整个操作不保证在 100ms 内结束。
3. **返回比较页时可见段落偏移。** 初次截图中，光标还在原修改块，可见内容已偏到后续段落。只恢复像素值受长文换行高度估算影响；恢复时两栏滚动还会互相覆盖。改为在卸载前捕获编辑器的滚动锚点和可见行，差异对齐完成后再校准位置，并把恢复期间的程序滚动与用户开始交互后的联动分开。回归分别核对两栏往返前后的首个可见段落。

过程中还修正了两处测试假设：改变基线后再执行“查看版本差异”会打开当前 Canon 的另一比较页，不能用它冒充返回旧标签；工具栏选中块后显示“当前 / 总数”，精确计数断言须覆盖这种真实文案。两者没有改动产品的版本身份与导航规则。

整套回归第一次为 41 / 42：失败在已有的 500 版本查找用例，实际提交编号前 16 位恰好全是数字，产品把它当成版本号而返回空结果。保留短数字只找版本的规则，超过现有版本号位数的数字串允许匹配提交编号前缀；补确定性的纯函数回归，并重跑整套桌面。不是通过重试掩盖偶发失败。后续整套回归另遇审稿窄窗用例找不到意见选择器：缩窗后在等待两帧之前就分支判断右栏入口，违反现有测试规范；把等待移到分支前，保留展开后的等待。产品审稿布局未改。

## 内容与编辑现场

10 万与 100 万字符均覆盖：

- 输入、撤销、重做；阅读 / 编辑切换后继续撤销。
- 编辑页与比较页往返；另一视图改变共享正文后旧栈失效。
- 选择 r1 基线，准确识别 13 / 113 处分散差异；逐块还原只改变当前短块，返回后可撤销还原。
- 双栏切为单栏，差异数量保持；继续输入后立即重载，未保存全文逐字保留。
- 手动保存、读取磁盘全文比对，再次重载，结尾与文件仍一致；无 renderer 未捕获异常。

撤销栈只在本次窗口生命周期内保留，重载后恢复的是草稿而不是旧撤销栈。已有 CAS / 外部改动保护继续由原桌面用例覆盖；本轮没有声称验证断电、强杀进程或无限容量的草稿存储。

## 响应速度与边界

原始测量见 [measurements.json](measurements.json)。百万字符单文件首开阅读约 2.2 秒，输入存在超过 100ms 的样本；约 1 万 / 10 万字符明显更轻。输入仍同步序列化共享工作区和持久草稿：专项观测中百万字符一次写入约 204 万字符，`setItem` 自身约 6–10ms，尚不含序列化和渲染。没有用延迟持久化掩盖开销。

最终代码独立复测（毫秒；比较为末尾一处补写，分散修改的正确性另由上述回归覆盖）：

| 实际字符数 | 输入中位数 / 最慢（5 次） | 首次打开比较 | 切回编辑页 | 重载保留草稿 |
| --- | --- | --- | --- | --- |
| 10,042 | 25 / 38 | 259 | 65 | 138 |
| 100,056 | 25 / 38 | 282 | 55 | 138 |
| 1,000,088 | 58 / 143 | 325 | 93 | 214 |

本轮改善是撤销连续性、比较精度与切页位置正确性，不宣称输入速度已经提升。极端单文件阅读与持久化开销仍作为已知限制；后续结合真实连续创作负载判断是否需要拆分草稿持久化或阅读渲染，不能把本轮压力数据外推成整部长篇的性能保证。
