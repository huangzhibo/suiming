# Agent 持续修改与作者多文件编辑

日期：2026-10-17。使用公共样例与临时作品目录；桌面经 `launchDesktop` 隔离配置、凭据与应用数据，模型响应以确定性闸门控制。没有操作真实作品、自动保存文件或创建 worktree。决策见 [ADR-0035](../../adr/0035-shared-checkout-write-protection.md)。

## 发现与修改

- 先补失败用例，复现 Agent 读后作者保存、迟到 `write` 仍覆盖作者的缺口；删除和复制覆盖也需要同一保护。文件工具记住本轮实际读取的 hash，覆盖前先核对它，再由原有 `FileMutation` 核对落盘前的变化。无读取依据先拒绝，读取后变化要求重读再调整；新建、同内容复制不增加读取要求。
- `edit` 仍允许修改唯一匹配的片段，保留作者在其他段落的内容；只有整篇版本仍已知时才能继续整篇写入，避免局部修改成功间接放行旧全文。
- 复现 `move` 读取源文件后、准备删除前作者保存：原实现会把旧内容搬走并删除新内容。增加源字节与删除前 hash 核对；此处准备失败不创建目标。执行阶段的批量原子性不在本轮增加。
- 版本按原始字节计算，带 BOM 的 UTF-8 文件不会被误判冲突。非 UTF-8 文件的 `read` 只确认版本与大小，不展开内容；这样复制覆盖 / 删除仍可先读核对，且不要求模型转录二进制。
- 旧 Harness 测试的静态模型响应补上实际读取，再验证原来的提交、对账、上下文折叠、打断和提交回执恢复；没有删掉这些断言，也没有在通用 fixture 中自动插入读取来掩盖错误。

## 桌面组合验收

新增 `concurrent-file-editing.test.ts` 使用真实 Electron、IPC、Harness 与文件工具，faux 只控制模型响应时序：

1. 甲、乙两文件各有未保存草稿；Agent 读甲后停在模型请求阶段。
2. 作者保存甲，磁盘完成写入但 IPC 回执暂扣；作者继续输入并切到乙。
3. 放行 Agent 的旧全文结果，断言工具拒绝；Agent 重读甲、保留作者保存内容后继续修改。
4. 放行迟到保存回执：甲继续输入的草稿保留、乙草稿与焦点不变，甲显示与新磁盘版本的冲突。
5. 作者比较并合并，以外部版本设基线；Agent 再次写甲。再次保存被挡住，旧合并稿和新磁盘内容均保留；重新比较合并后成功手动保存。
6. 重载后乙草稿保留，乙磁盘仍是原文，没有自动保存；渲染错误为空。另以保存执行前的闸门验证：请求发出后磁盘变化，由 Runtime CAS 实际拒绝，迟到失败不串页、不抢焦点，重载后原稿仍在。

既有完整套件继续覆盖外部删除 / 重命名、窄窗、分屏、切页返回、跨作品同路径隔离、停止后切换与重载恢复；不另建一套测试应用。

## 真实模型验证

[probe.mts](probe.mts) 在临时公共样例里运行生产 Agent 与真实模型：第一次 `read` 返回之前插入作者保存，让模型实际收到旧内容；随后断言 `write` 被拒、模型重读并保留双方内容。同一 Session 下一轮再次整篇修改，必须重新读取，Canon 未被自行提交。第三轮确认二进制附件的读取版本、原样复制覆盖与删除。

复跑前先构建，执行期间不要重建 dist：

```sh
node --env-file-if-exists=.env --import tsx docs/validation/2026-10-17-concurrent-editing/probe.mts
```

模型使用现有配置与凭据存储的正常调用路径，不撤销授权、不复制刷新凭据；运行作品与执行记录都在临时副本，结束后清理。该测试只验证冲突恢复，不代表真实长篇质量或持续多小时运行。

## 结果与限制

首次真实探针因临时目录的真实路径与入口路径不同，未触发并发注入，不计通过；校正注入位置后两轮文本验证通过（10 次调用）。最终补充附件兼容验收的结果见下。

| 验证 | 结果 |
| --- | --- |
| 全仓检查 | `npm run check` 通过；收尾文档另查链接与规范一致性 |
| 全仓测试 | 489 / 489，0 skip；含工作台 77 / 77，新增文件并发 / 编码用例 7 条 |
| 完整 Electron | 76 / 76，0 skip，含原生全屏；约 515 秒 |
| 最终相关 Electron 复验 | 并发编辑与回执 4 / 4；截图等弹层关闭后再采集，追加单项 1 / 1 |
| 真实模型 | `openai/gpt-6.1-sol`，最终 3 轮、15 次调用全部确认；真实冲突、同 Session 续写、二进制附件复制 / 删除通过 |

最终真实模型输入 20,042 token、缓存读 98,816、输出 694；估算 $0.056906，不是账单。两轮文本验收中第一次旧写入确实被拒，重读后作者句子与模型补写均保留，下一轮再次读取；附件内容逐字节一致，未自行推进 Canon。模型结果、完整 checkpoint、凭据和临时作品未提交。

截图走查确认：外部文件与作者未保存稿在原比较页分开呈现；工具失败在原动作详情中可见，冲突入口仍在文档工具栏，没有新增横幅或卡片。未保存内容不会被 Agent 读到；受控保存可检测冲突，外部任意进程写入不是全局锁保护。内存中的读取版本不跨轮持久化，不改变 Canon 或草稿格式。
