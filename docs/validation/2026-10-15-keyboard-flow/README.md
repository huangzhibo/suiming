# 键盘连续操作与焦点恢复（2026-10-15）

## 范围与隔离

沿路线图验证「检索 → 打开 → 编辑 → 保存 → 返回」，并组合菜单退出、未保存关闭、外部修改冲突、重载、窄窗口和分屏。保留已有页面布局与可视化，不改变作品规则或执行协议。

所有操作在真实 Electron 中进行，使用公开样例的临时作品、独立 user-data 和 `launchDesktop` 隔离配置 / 凭据。核心连续操作只通过键盘完成，断言实际焦点而不以测试的 `focus()` 补齐产品行为。没有调用真实模型或访问日常账号，因而不产生新的 Langfuse 或真实创作质量证据。

## 发现与修正

- 新标签打开选择页后焦点留在原控件，不能直接输入查询。进入活动窗格的选择页时聚焦搜索框，分屏切换活动窗格时不重复聚焦。
- 侧栏已经展开时，⌘ / Ctrl K 只改显示状态，没有把编辑器焦点转到搜索框。现在每次显式唤起均聚焦搜索。
- 长结果返回时只聚焦搜索框会让焦点落到屏幕外；现在随现有页面快照保留刚打开的条目，返回或重载后与滚动位置一起恢复。
- 侧栏固定截断前 60 个结果，后续条目不可达；补数量与更多入口，扩展后聚焦第一条新增结果。空白页同样处理更多按钮消失后的焦点。默认前 12 条并非访问历史，删除“最近条目”的误称。
- 两种搜索入口缺少一致的结果导航。复用一个键盘事件函数，在原有按钮上支持方向键、Home / End、Enter 与 Escape；不另建选择状态机，不拦截输入框的光标移动或中文输入组合。

先补端到端验收，旧实现分别在新标签焦点和搜索结果下移处失败。未保存关闭确认的取消与原光标恢复原本正确；测试最初把 CodeMirror 合并的一组快速输入误当成两步撤销，修正为撤销再重做验证，不因此改写编辑器历史机制。复验也纠正了两处用例问题：文件标题出现早于可编辑内容，快捷键前须等真实编辑入口；布尔 data 属性按属性存在定位，不假定其序列化为空串。长结果返回焦点与 60 条截断分别在旧实现复现后修正。

## 验收路径

- 新标签直接输入中文查询；组合期间 Enter 不打开结果，确认后打开人物，⌘ / Ctrl E 编辑，⌘ / Ctrl S 落盘；菜单 / 设置 Escape 回触发按钮，返回保留查询，重开与重载保留保存内容。
- 侧栏搜索首次 / 重复唤起均得到焦点，方向键移动结果与返回输入框；无结果 Enter 不导航，组合期间导航快捷键不生效。
- 未保存时关闭标签弹出确认，弹窗内快捷键不穿透到工作台，Escape 返回原编辑器与光标；继续输入、撤销与重做保留内容。
- 960×640 下完成搜索编辑；外部文件修改后保存冲突，原文件不被覆盖，取消弹窗后可从原光标继续修订；重载保留草稿。
- 分屏后用 Tab 到达另一窗格结果按钮，活动窗格切换不抢焦点，Enter 与编辑只作用于该窗格。
- 大量结果按批展开后可用键盘走到第 70 项；空白页原有 81 项搜索的返回、重载焦点、滚动和延迟目录恢复也纳入复验；目录等待期间作者移到对话输入框后，回复到达不抢焦点，继续输入仍写入对话草稿。

## 边界

中文输入法保护使用 Chromium composition 键盘事件，未模拟每一种系统输入法候选面板。键盘主路径与现有窗口回归不等于完整读屏或无障碍认证。正式签名、公证和真实服务商凭据撤销继续按路线图暂缓。
