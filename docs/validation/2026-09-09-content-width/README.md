# 内容页宽度验收

日期：2026-09-09。使用真实 Electron 工作台与 eval-022 临时副本，未修改作者原作品。常规前后截图均为 1460×940 窗口，左栏 200px、右栏 260px；另检查 960×640 窗口和收起两侧栏后的工作面。

## 调整

- 原作品页总宽 720px，扣去固定的 80px 留白后实际内容仅 640px；所有文档共用此限制，704px 的关系图必然需要横向滚动。
- 正文实际宽度提高到最多 720px，正文编辑使用同一上限；设计、人物、世界等文档及 Markdown 文件预览最多 960px。标题、属性、状态与正文沿同一页内边界对齐。
- 单页两侧留白随主工作面宽度在 20–40px 之间调整。并排对照保持两列，各列留白 16–28px，独立滚动并预留滚动条位置；长路径、属性与引用名称换行。原始文件源码和版本差异不限制内容宽度。
- 宽度由 CSS 控制，不引入设置、持久状态或额外按钮，不因拖拽或窗口缩放重建 CodeMirror。
