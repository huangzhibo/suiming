# 滚动条自动隐藏

2026-09-09，真实 Electron 工作台及 eval-022 临时副本。保留原生滚轮、触控板、键盘与拖拽，只控制滑块显隐；没有修改作者原作品。

默认隐藏滑块和轨道。按最新作者反馈，仅在实际滚动时显示，停止滚动 1 秒后隐藏；靠近边缘、悬停滑块和键盘焦点均不会单独显示滚动条。监听覆盖之后挂载的编辑器和 portal；卸载清理监听与计时器。显隐不修改 overflow、滚动条宽度或滚动位置。
