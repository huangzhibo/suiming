# Suiming 桌面 UI/UX 实际走查 · 2026-09-09

现有窄导航轨、目录、标签页和辅助栏可以继续使用。最先需要解决的是工作连续性和长内容布局：审稿页无法显示完整核对区、Agent 草稿重载后消失、最小窗口下工具栏被裁切。正文排版、编辑差异和明确的状态查询已经有可用基础。

用户复核后的修正：首轮对状态查询“清晰”的评价只覆盖查询边界，没有充分检查入口稳定性、重复导航和分栏一致性。状态能力需要重新融入工作台，不能只修复右栏恢复。详见[状态查询设计反思](state-query-reflection.md)。

## 范围与方法

自行运行 `npm run build:desktop`，通过 Playwright Electron 启动最新桌面产物并操作真实 renderer / IPC。使用 `eval-022-suiming` 的完整临时副本：9 卷、69 Beat、6 份正文、2 份 ReviewReport，当前 r8。默认窗口 1460×940，另查应用允许的最小窗口 960×640，均为 CSS 像素。

原作品 `~/stories/eval-022-suiming` 未改动。临时正文编辑只存在于 renderer，已撤销；Checker 返回 0 个候选文件变更。没有发起 Agent 委托、修改模型配置、调用付费模型、提交或恢复作品版本。本轮只新增审查记录与截图，没有实现以下建议。

## 完整走查路径与截图

### 1. 打开作品与设计页 · 可用，信息层级待优化

启动后直接恢复可编辑的作品，目录能区分有正文和仅设计。默认展开 69 个 Beat，主页面以协议字段和审稿标记占据标题下区域；建议先突出作品内容与当前任务。

### 2. 全书故事轴与按卷展开 · 可用，全书密度较高

总览能同时看覆盖、承诺和人物分布；进入一卷后，9 个 Beat 及对应关系更容易辨认。保留两级观察方式，优化总览的关系显隐和键盘导航。

![03 按卷查看故事轴](03-volume-axis.png)

### 3. 阅读正文 · 排版良好，工作区可更聚焦

查询明确显示 Beat、进入前／本幕变化／结束后、已提交 revision 和来源链接；“未记录不等于没有发生或人物不知道”有必要。全部对象查询还包含大量与当前幕无直接关系的未开启承诺，可提供“与本幕相关／全部”筛选。收起再展开右栏会切回 Agent。

## 可访问性与证据限制

- **可见风险：** 故事轴和人物轨迹依赖细小标记、低对比度辅助文字、悬停说明；全书图实测 453 个可聚焦按钮，Beat 命中区域 8×42px。建议方向键导航、较大命中区及等价的文字列表。未用屏幕阅读器验证 SVG `role="img"` 下的交互按钮是否完整暴露，不据此宣布其一定不可访问。
- **已复现的布局风险：** 支持的最小窗口裁切核心操作；长审稿报告没有可到达的完整内容区域。均有截图和 DOM 测量支持，不只是主观视觉评价。
- **已有基础：** 工具按钮有可访问名称，输入框有标签，主要选择控件有 radio 语义；这不等于完成键盘、焦点顺序、读屏或对比度合规验收。
- **未覆盖：** 新作品完整创建、真实 OAuth、模型调用、流式长委托、暂停／失败／恢复、冲突解决、提交／回滚、导入导出、其他屏幕缩放比例，以及真实作者的完成时间与满意度。没有将这些状态标为通过，也没有把截图审查当成长篇质量证明。
- **采集可信度：** 22 张本次自启动实例的截图均已打开检查；加载和动画中间帧已重拍。前一次 Computer Use 的过期截图不进入证据集。记录期间 renderer `pageerror` 为 0；这不表示业务流程没有问题。
