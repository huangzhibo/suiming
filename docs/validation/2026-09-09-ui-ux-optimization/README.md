# UI/UX 一致性优化验收（2026-09-09）

基于[全局审计](../2026-09-09-ui-ux-audit/README.md)与[状态查询设计反思](../2026-09-09-ui-ux-audit/state-query-reflection.md)，在现有 workbench-v7 上优化。使用同一份 eval-022-suiming 临时副本（9 卷、69 Beat、6 篇正文、2 份 ReviewReport、r8）；原作品未修改，视觉检查不启动模型。

## 已实现

- 「故事状态」固定入口，查询条件只由明确动作改变；三种边界只在侧栏切换。Beat 页去掉重复动作与 Beat 下拉，人物等对象按需更换位置，未选位置时不自动查询首幕。
- 主区、目录、搜索和所有右栏模式复用 37px PanelToolbar，分割线统一归工具行所有。
- 右栏收起再展开恢复原模式。小于 1180px 时一次展示一侧，主动打开的一侧优先；放大后恢复原先的两栏偏好。编辑保存动作另占一行，状态信息按需换行且不遮住内容与处理动作。底部后续收紧为单行 24px 的贴底状态栏，移除胶囊装饰及上下留白；下方截图保留当时的胶囊样式。
- Agent 草稿及完整引用按作品与委托保存，重载恢复；新建与切换委托保留各自输入，成功发送清除对应草稿。引用可预览，后续浏览不改写其版本和结果。
- Review 长总结不再作页面大标题；结论与问题区域独立滚动且不超过可用高度的 45%，被审快照与当前稿持续并置。选择跨文件 finding 时同步当前稿，并滚到对应段落。
- 撤销或保存本页后清除失效的未保存提示。

## 验收

使用同一窗口尺寸对照审计截图逐项复核。常规检查 `npm run check` 通过；`npm test` 为 252 通过、9 跳过、0 失败。桌面回归 5 项均通过：最终整组中 4 项通过，状态查询用例因同名位置与来源导致选择器歧义，限定位置标题后单独重跑通过。覆盖固定入口、查询空态、主体筛选与清除、来源导航和重载、工具行对齐、面板恢复、完整引用与草稿隔离、长报告滚动、最小窗口控件边界与撤销提示。
