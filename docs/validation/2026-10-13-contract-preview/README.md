# 期待路径与预览走查（2026-10-13）

范围：只调整期待页的信息层级、横纵换向和原文预览；领域规则、其他对象的图形结构不变。采用作者确认的横纵对比方向，决定见 [ADR-0021](../../adr/0021-contract-progressive-preview.md)。

## 验收与迭代

- 先补「原文不常驻」验收，旧实现按预期失败（2 段常驻摘录），再替换展示。
- 两个与六个事件宽窗横排，同组六事件缩窗后纵排；空、单点、同节三个阶段、30 个事件和非法候选均保留真实数据，不插空阶段。每节只显示一次序号，长标题不截断。
- 首轮发现原来的 960px 文档上限让六节点永远不能横排，期待页扩大到最多 1260px；短路径每节点不超过 280px，仍保持紧凑。
- 首轮截图发现纵向预览以整行定位会误判右侧空间，翻到左侧盖导航；改为具体标题锚点，补右侧空间充足时不得翻转的断言。右栏展开后内容区 552px 改为纵向，不以窗口宽度代替内容宽度。
- 鼠标悬停标题、图形节点，移入预览阅读，键盘聚焦显示、Esc 关闭、Enter / Space 直接导航、图形点击预览与卡片内来源跳转均覆盖。缩窗换向关闭旧卡片，页底和窄窗预览保持窗口内 8px 留白。
- 异常提示常驻；来源读取只在预览打开时执行，仍使用原有缓存、96 字原文摘录及失败重试通道。
