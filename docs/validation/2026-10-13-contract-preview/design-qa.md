# 期待路径视觉复核

- source：作者选定的横纵对比概念图。
- implementation：公共三国示例中的「三约暂降与寻兄」，同一组 6 个事件，预览第 127 个情节。
- comparison：[同一画布中的参考与实现](comparison.jpg)。原生截图为 2× 像素，横窗 1600×940 CSS px、纵窗 1120×940 CSS px；比较图裁出进展区并缩放，不据生成图推算精确尺寸。两种实现字号完全相同，概念图上的字体不一致未照搬。

## 发现、修正与复验

1. P2：六事件受文档上限限制无法横排。期待页放宽至 1260px，1600px 窗口复验横排；其他页面仍保持原宽度。
2. P2：纵向预览误翻至左侧并遮导航。锚点从整行移到标题，1120px 窗口复验向右，卡片与触发标题间保留 8px。
3. P2：552px 内容区仍横排，不符合窄窗阅读目的。增加 560px 下限，960px 窗口同时打开右栏后复验纵排。

## 五项复核

- 字体：沿用工作台系统字体；标题 14px，阶段、序号、预览摘要 12px，不按方向缩字。长标题换行，无省略隐藏。
- 间距：横向阶段、节点、内容共用网格行；纵向默认一行一事件，复杂阶段、警告允许增高。预览浮层不改变路径几何位置。两节点不横跨全页。
- 颜色：建立蓝、推进琥珀、回应绿，均使用共享 token；灰色连接线和中性预览与其他页一致。状态依靠文字与图形同时表达。
- 图形：沿用 Lucide 标准图标和 CSS 连线，无新位图资产。概念图的较大圈、装饰阴影和箭头未机械复刻，保持现有系统规格。
- 文案：使用作品原始完整标题与摘录，未采用概念图里的简写。原文标签只出现在预览；常驻去除无推进说明，异常保留。

final result: pass。上述 P2 已修正并重拍；概念图与产品的字体、控件规格差异属于有意统一。交互与几何断言补充视觉证据，仍需持续收集作者实际使用反馈。
