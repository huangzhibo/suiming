# 2026-09-09 导航与文档交互验收

依据：[优化方案](../../history/workbench-navigation-optimization.md)。本轮验证当前实现，不沿用上一轮截图作为通过证据。

## 实现与验证

| 场景 | 结果 |
| --- | --- |
| 顺序、文件、身份、依据、搜索切换 | 只更换左栏；中央页面、面包屑、阅读位置和故事状态条件保持，各左栏保留展开、排序与滚动 |
| 作品与原始文件 | 作品页显示卷 / 对象语义位置；原始文件页显示相对路径，支持定位文件树、复制路径、Finder 与返回作品 |
| 内容视图与任务操作 | 正文 / 设计 / 并排对照只切换表示；分别编辑明确文件，返回原视图；版本差异固定左侧 revision，右侧区分 checkout 与未保存缓冲 |
| 普通导航与显式保留 | 普通打开复用当前未保护 tab，或激活已有目标；固定与未保存 tab 保留；显式新开与复制允许副本 |
| 快捷键和菜单 | Cmd/Ctrl 点击、中键后台新开，Shift 激活；右键有等价入口。Cmd/Ctrl T、W 分别新建空白页、关闭当前页；组合输入不触发快捷键 |
| 草稿、关闭与重载 | 同文件的作品页 / 原始文件页共享内容与 CAS 基线；重载恢复光标、选区和草稿且不写盘；最后一个持有草稿的视图关闭时可保存、放弃或取消 |
| 文件边界 | 辅助文件不进入作品 diff / commit；未知保留路径不拖垮文件入口；路径越界、symlink、二进制写入与 evidence 改写被拒绝 |
| 既有能力 | 故事状态查询、Agent 引用与草稿、外部修改合并、Review 快照、SIGKILL 后恢复和模型设置通过回归 |
| 布局 | 1460×940 与 960×640 下工具栏边界一致；三栏工具行均为 37px。长路径截短中间层，完整路径保留在 tooltip；窄窗口收纳内容视图 |

## 检查结果

- `npm run check` 通过：文档、宪法、host 文件、Story 隔离、Biome、TypeScript、web 与 integration 契约。
- `npm test`：266 项，257 通过，9 项按原有外部环境条件跳过，0 失败。
- Electron：6 个场景通过。新增场景覆盖左栏独立、阅读选区、共享草稿、只读源码、固定 / 新开、关闭选择、重载、辅助文件保存与非法文件修复入口。
- 单元测试新增：tab 历史快照、保护与去重、保存途中继续输入；真实 Local Project 验证辅助文件不进入作品提交及文件权限边界。
- 桌面实测采用 `eval-022-suiming` 的临时副本；作者真实作品未修改。临时辅助文档只用于布局验证。
- Vite 保留既有大 bundle 提示；本轮没有把 bundle 拆分扩为新的工程范围。

## 明确边界

- 这一轮没有新增文件的批量移动、重命名或删除。文件树服务于浏览与修复，作品提交继续经过既有 codec / Checker。
- portable evidence 保持只读。二进制及超过 4 MB 的文件在文件页展示大小与说明，通过系统应用打开。
- 草稿保存在本机客户端；恢复不会创建候选或提交。存储失败时显示错误并保护窗口关闭，不能将未持久保存的内容宣称为已保存。
- 本轮未改变故事质量结论、Story Language、Run / Harness 或 Cloud 产品范围。
