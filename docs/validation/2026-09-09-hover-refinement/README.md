# 提示精简与面包屑悬停反馈

作者指出：完整的“黄天将裂 / 五色棒下”又被 Tooltip 原样重复，遮住内容却没有提供新信息。后续 Obsidian 截图体现的是单个路径段的灰色悬停反馈，提示也跟随该段；完整的 `source` 名称重复提示同样没有信息增量，不作为照搬依据。

## 修正

- 面包屑按段反馈，可点击父级使用浅灰背景和圆角，替换下划线；键盘保留可见焦点，当前名称没有动作时保持普通文本。
- 完整名称不弹出重复提示。截断时仅补全该段，中间路径折叠时由「…」显示完整路径。
- 标签页、最近作品的名称与路径、无诊断的文件树根项共用 `OverflowHint`，按实际文字溢出判断。提示打开期间监测宽度，文字恢复完整后关闭；不为每个未打开的条目持续监听尺寸。
- Markdown 的纯 URL 标签不重复提示地址，有名称的链接仍补充目的地址。导航状态、嵌套文件的相对路径、诊断、图标动作、禁用原因和图中标记保留有用说明。
