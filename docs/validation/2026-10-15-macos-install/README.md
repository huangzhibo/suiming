# macOS 安装与回退验收（2026-10-15）

本轮建立自含 macOS 预览，并直接运行从 zip 解出的生产应用。操作协议见[macOS 预览](../../macos-preview.md)，决定见 [ADR-0028](../../adr/0028-macos-preview-delivery.md)。

## 环境与隔离

macOS 26.6.2、arm64，安装包内 Electron 44.6.0 / Node 24.21.0。打包使用锁定依赖和 npm 生产依赖闭包；不带仓库 `.env`、测试入口、开发服务或本机作品。应用在隔离 `Applications` 目录中解压和替换，配置、凭据与 userData 均单独指定；测试不读取日常模型配置，不调用真实 provider，不撤销账号，也不写入系统应用目录。

本轮不是签名发行测试：未签名、公证，没有验证下载隔离 / Gatekeeper、Intel、其他 macOS 版本或独立机器。两个包都是 0.1.0 开发构建，前者生产源码来自本轮修复前的 `67ce426`，后者带本轮修复；这验证的是相同执行库 v6 / Story Language 的构建替换，不是历史正式版本跨度或跨 schema 转换。

## 自动复验入口

- [打包脚本](../../../scripts/package-macos.mjs)：`npm run package:mac`，可给输出目录；本轮下载等待后改用与版本、架构匹配的官方 Electron zip 缓存，没有更换 Electron。
- [生产包 smoke](../../../apps/desktop/test/packaged-smoke.ts)：给出 `SUIMING_TEST_MAC_ZIP` 和 `SUIMING_TEST_PREVIOUS_MAC_ZIP` 后运行 `npm run test:mac-package`。缺少包会失败，不退回开发入口。真实系统目录对话框的返回值由测试指定，实际创建 / 打开仍走按钮、preload、IPC、Runtime 和 SQLite；没有在包内注入 faux provider。
- [启动失败回归](../../../apps/desktop/test/startup-recovery.test.ts)：默认桌面套件覆盖最近作品重开、显式启动路径、最小窗口错误几何位置，以及失败后打开其他作品。
- [真实长任务生产包回读](production-history.mts)：指定已静止的公共作品冷备份和生产可执行文件，复制到新隔离目录，只读原对话、重载并比较持久状态。

## 发现与迭代

1. 新增启动回归后，修复前最近作品重开失败的提示断言超时：代码只有 console 日志，界面当成首次启动；`--project` 路径还会让创建窗口前的 Promise 拒绝。改为保存本次启动失败，复用现有命令错误信封与工作台显示；正常打开后清除，失败不覆盖最近作品。
2. 首轮生产包验收通过后检查截图，错误虽然可见，却位于大型欢迎文案下方。补最小窗口几何断言，修复前失败。错误态现显示“作品未能打开”，原因在操作按钮之前，长路径可换行，内容可滚动；不再用首次欢迎文案挤掉排障信息。
3. 安装测试始终使用真实 `.app` 的生产入口；进一步将进程 cwd 切到隔离目录，避免依赖开发仓工作目录。安装与常规桌面套件顺序执行，避免相互抢占窗口焦点。

## 数据保全矩阵

| 场景 | 核对内容 |
| --- | --- |
| 空配置首次启动 | 欢迎页可见，`app.isPackaged` 为真；包内 Node / SQLite 能运行 |
| 新建作品 | 真实按钮新建，产生一个 Canon 起点；不需要本机 Node 或 Git 进程 |
| 安装前准备 | 三版 Canon、一个原对话、一个已完成子任务、长助手回复、未提交候选；由受控模型预先生成，安装测试只读 |
| 替换 `.app` | 自动重开原作品；所有历史版本快照、候选、Session / Task、持久事件相等；执行对象逐文件 SHA-256 相等 |
| 原对话与重载 | 原回复可读，重载保留；没有增加模型调用、任务、事件或版本 |
| 故障注入 | 仅在隔离副本将 schema 标为 v999；新构建显示不能自动升级，拒绝前后 SQLite 字节不变 |
| 回退 | 退出应用，恢复完整旧包、完整作品冷备份及本次 userData；原作品、三版 Canon、原对话与任务再核对通过 |

## 最终结果

- 界面迭代后的生产包 smoke：1 / 1 通过；三版 Canon、一个对话、一个子任务、长回复和未提交候选保留，127 个外置执行对象逐文件 SHA-256 一致。最小窗口截图确认错误与打开入口完整可见。
- 真实长任务冷备份的独立副本：生产应用读回原审稿完成回复，重载前后相同；7 个 Canon 版本、1 个 Session、14 个 Task、10,366 条持久事件以及当前候选保持一致，渲染异常为零。只读，不新增真实模型调用。
- 包内检查：ASAR 共 24,013 个条目，没有仓库 `.env`、`.suiming` 或桌面源码 / 测试入口。约 405 MB 的 `.app`、143 MB 的 zip；没有另带开发服务器。
- `npm run check` 通过；全仓 502 项中 497 通过、5 个原有外部集成 skip；完整桌面 48 / 48 通过、0 skip，包含原生全屏。安装包 smoke 单独计算，不混入常规桌面数量。

这里只证明本机构建可安装运行与当前格式的数据保留。签名、公证、真实下载隔离、独立机器、其他架构，以及跨 Story Language / 执行库格式升级均未完成；不存在自动更新或自动旧库转换的承诺。
