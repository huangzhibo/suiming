# 大量版本查找与长对话详情验收（2026-10-14）

## 范围与隔离

按路线图先完成版本检索，再复测真实长对话。版本规模使用两节公共样例的 10 / 100 / 500 个同内容 git 提交，仅验证选择与导航规模，不冒充创作或 Checker 证据。长对话使用三国历史作品的独立副本，数据库以只读连接备份，原作品与历史不修改；通过统一测试入口隔离配置、凭据和观测。不发新的模型请求。

## 版本查找

三个入口共用搜索：版本页、比较基准、材料侧栏。材料只列最近 10 条，全部版本仍可检索。rN 与 Canon 顺序保持一致，版本号或提交编号精确匹配优先；无查询时最近在前，筛选时显示匹配数，不截断结果。

10 / 100 / 500 个版本均实测以下路径：从材料进入、查指定版本、完整提交编号前缀检索、无结果后清空恢复、键盘选择和 Esc 焦点返回、跨版本保留指定文件、无变更提示、重载恢复、960×640 窄窗弹层不越界。比较页既有草稿 / 固定基准与导航回归一并验证。未添加假的摘要、日期或对话归属；按故事内容找未知版本仍未实现。

走查迭代三处：材料侧栏不再列满几百条；搜索标题从固定总数改为命中数 / 总数，避免只剩一个结果却显示几百个的歧义；最终截图发现纯数字还会匹配提交编号片段，现明确只按版本号查找，500 版本输入 21 从几十条噪声结果收敛为 11 条版本前缀匹配，r21 排首位。决定见 [ADR-0022](../../adr/0022-searchable-version-history.md)。

## 长对话读取

选真实历史中 1314 条动作的单个子任务。修复前 `ActionDetailReader` 打开一条动作会解开完整 checkpoint；修复后只走 actions 的键与分块，匹配后读该动作的参数和结果。每块最多 16 条，未命中让出事件循环；不新建索引、不改存储格式、不裁剪历史，完整恢复沿用原解码路径。缓存仍有界。

同一副本，前后各三轮，首项与末项各自使用新 store / reader。基线取修改前 reader，使用同一完整解码实现；串行测量，不同时构建或跑桌面。计时包含实际本地对象读取；10ms 计时器采样事件循环延迟，结束后再等待 20ms 收最后一次采样。这里的冷读指应用缓存冷，不指磁盘缓存冷。完整逐次值见 [measurements.json](measurements.json)。

| 场景 | 修复前 | 修复后 |
| --- | --- | --- |
| 首项首次读取 | 337–382ms | 2–6ms |
| 末项首次读取 | 318–372ms | 85–90ms |
| 重复同一项 | 四舍五入后 0ms | 首项 0ms；末项 2–3ms |
| 首项之后读下一项 | 四舍五入后 0ms | 1ms |
| 详情读取期间最长事件循环延迟 | 90ms | 2ms |
| 首项冷读对象数 / 字节 | 5474 / 7,528,814 | 21 / 42,825 |
| 末项冷读对象数 / 字节 | 5474 / 7,528,814 | 1402 / 2,080,736 |

重复读取末项仍要遍历编码的动作键，所以比缓存完整解码对象略慢；收益是首次不再读全量消息和无关结果。更大规模的任意定位仍是顺序扫描，不声称常数时间。

Electron 另开三个独立窗口复验：切换历史对话到目标子任务可见为 454–494ms；输入一段未发送文本并读回为 39–87ms。子任务尚未展开前，从 renderer 经真实 IPC 读首项为 7–34ms、重复 1–2ms、下一项 1–7ms；随后第一次读末项为 275–369ms，该期间主进程计时器最大延迟 6 / 54 / 59ms。已读动作从点击展开到结果可见为 141–191ms。IPC、点击和独立 Node 测量边界不同，不能混成一组前后改善比。

探索阶段曾先展开全部动作组再测详情，失败行自动展开已经预热同一 checkpoint，因此那组数不作为冷读证据；最终计时在展开子任务之前完成。当前实测支持历史浏览变快，不证明运行中流式输出、百万汉字编辑或所有恢复路径性能已达标。

## 布局缺陷与复验

真实历史展开后发现对话视口仅 375px，内容宽达 517px，横向滚动 42px。短参数中的连续编号参与网格最小内容宽度计算，把整个动作列表撑大；长文本块单独测不会暴露它。

先补包含子任务委派短字段和长结果的 Electron 用例，修复前稳定失败（375px 视口、438px 内容、横向偏移 30px）；再将动作列表与详情的单列网格限制在可用宽度，内容照常换行，不隐藏或删掉输出。修复后真实历史侧栏为 375 / 375px，主工作面为 1164 / 1164px，均无横向偏移；三次切换、详情、输入、重载无渲染异常。截图在隔离验证目录检查，不把真实执行内容提交公开仓库。

## 余项

大量版本可以直接按编号查找，尚不支持按故事修改内容找稿。长对话已验证历史详情读取，仍需结合持续创作验证运行中交互、长正文编辑与差异比较；下一步只在[路线图](../../roadmap.md#6-立即执行队列)维护。
