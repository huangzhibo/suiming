# 悬停提示检查与中文适配

日期：2026-09-09。范围包括左右导航、全局动作、标签页、文档工具、文件树、分栏手柄、故事轴与轨迹、引用、Agent 和模型设置。沿用真实 Electron 预览和已有工作台组件；视觉检查使用 eval-022 的临时副本，交互回归使用独立 2 Beat 样例，没有修改作者原作品。

## 发现与修正

| 问题 | 修正 |
| --- | --- |
| 导航提示罗列 `StoryOutline / refs / subjects / evidence`，作者需要自行理解字段 | 入口保留简短中文名称，第二行说明用途，如“被引用／查看哪些作品内容引用了当前对象”。技术字段只在来源或诊断信息中出现。 |
| 关闭标签、标签列表、移除引用、缩放与对话框关闭按钮缺少悬停说明 | 补齐同一种 Tooltip；对话框默认的 `Close` 改为“关闭对话框”。标签名被截断时可查看全名。 |
| 禁用动作看得见，但无法通过 hover 或键盘理解原因 | 检查、提交、前进后退、文件定位、折叠文件夹、创作意图及缺正文的对照选项说明具体原因。禁用图标与分段选项保持可聚焦，交互逻辑阻止执行；窄窗口菜单直接显示对照不可用原因。 |
| “展开／折叠全部”“显示 id”“按引用数排序”未说明当前点击会做什么 | 提示随状态显示“折叠全部卷”“隐藏标识符”“恢复默认排序”等；执行记录的工具栏与行内展开状态同步。 |
| HTML title、SVG title 与控件 Tooltip 混用；长路径可能过宽 | 交互提示统一为 Tooltip，保留图表本身的 SVG 可访问标题。最长 320px，距边缘 8px，支持中文和无空格路径换行；关闭时立即隐藏。 |
| 提示与分段选择共用 `data-state`，存在样式冲突 | 选中样式改用分段选项自己的 `aria-checked`，Tooltip 状态不再影响高亮。 |
| 新增 Tooltip 可能影响弹出层触发和初始焦点 | Hint 转交触发器事件与 ref，作品切换和标签页菜单仍可打开；阅读型帮助窗口初次聚焦内容，避免自动弹出关闭按钮提示。 |
| 正文存在就提示“已提交”，审稿和承诺直接暴露英文状态 | 区分正文未提交、仅有设计、已提交与设计更新；使用“审稿需修订”“关联内容已有更新”“开启／推进／收束承诺”等中文说明；资源消耗与毁坏分别表达。 |

提示用于补充信息，可见文字已经清楚的按钮不再重复解释。Beat 在领域模型中的含义保持不变，常用操作中称“情节”；不把它误译为章节，也不把引用人物解读为人物必然出场。来源字段与文件路径保持精确。

## 验证

新增 Electron 场景已验证：真实鼠标移动与悬停、移入提示继续阅读、Escape 关闭、键盘查看禁用原因、折叠按钮名称更新、禁用对照无法选中、存在候选但还有未保存编辑时鼠标／Enter／Space 均不提交、故事轴 SVG 提示、960×640 下长文件名换行不越界、设置对话框先关闭 Tooltip 再关闭对话框。提交保护同时核对 revision、磁盘正文、编辑器内容和 Run 数量。

最终验证：Electron 完整回归 **8 / 8** 通过，涵盖既有创作闭环、重启恢复、目录初始化、模型设置、导航与分栏，以及新增提示场景；前端单元测试 **14 / 14** 通过。`check:web`、`check:types`、前端生产构建、文档链接、前端与桌面测试代码的 Biome 检查、`git diff --check` 均通过。构建保留既有的大 chunk 提醒，本轮未调整拆包。

本次验证的是提示的文案和交互机制；未进行屏幕阅读器实机朗读验收，也未重新验收真实 provider 登录。

## 导航条目提示方向修正

作者指出，纵向导航的提示放在下方会盖住相邻条目。已将大纲卷、情节和文件树条目的 Tooltip 统一设为右侧优先，继续使用原有延迟、换行和边缘避让。

同一 1460×940 窗口下，[修正前](08-navigation-before-position.png)的提示覆盖了后续条目；[修正后](09-navigation-after-position.png)显示在列表右侧。实测导航行 x=52px、宽 175px，提示左缘 x=243px，相邻行不再被遮挡。`check:web`、前端构建、Biome 和文档链接检查通过。

提示专项 Electron 场景重新通过，覆盖了文件树长路径在 960×640 窗口中的显示。测试入口增加显式激活 Electron 应用，解决后台窗口首次 hover 超时；实际页面的提示延迟与触发逻辑未改动。
