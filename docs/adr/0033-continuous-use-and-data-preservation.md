# ADR-0033：持续使用与数据保全进入产品验收

- 日期：2026-10-16
- 状态：接受

## 背景

多轮桌面走查已形成持续使用、草稿恢复与自主验证要求，但顶层需求仍偏重单次功能闭环，并残留“会话是一次性的”和未知请求需要作者确认的旧表述。仅在实施记录中修正，会使后续工作继续受过时目标影响。

## 决定

保持 C / R / A 质量目标、本地优先及 repository-native 边界。将持续使用、数据保全和验证分工纳入[需求与目标](../vision-and-requirements.md)；停止与恢复继续服从现行 Harness，不重建暂停确认流程。

保全责任不以是否属于 Canon 划线。明确作品目录与桌面应用草稿的范围，开发期不兼容策略不豁免真实数据保全；不因此新增备份格式、恢复服务或通用迁移层。延续 [ADR-0027](0027-repository-recovery-boundaries.md) 的目录恢复方案，并澄清它不包含目录之外的应用数据。

## 文档与验收边界

需求文档维护长期承诺；工作台设计维护交互及性能口径；Harness 维护执行规则；恢复与安装指南维护操作前提。当前状态和验证记录维护能力证据，路线图维护具体队列与本阶段邀请条件。本次只校准文档，不把受控测量提升为长期性能承诺，也不宣称数据迁移或文学质量新增验收。
