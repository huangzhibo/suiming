# ADR-0023：长文编辑现场与差异精度

- 日期：2026-10-14
- 状态：接受

## 问题

编辑器随标签或阅读视图切换卸载，草稿仍在，但 CodeMirror 的撤销栈丢失。长文比较还受到默认扫描长度限制：分散的小修改被粗化为大块，逐块还原的范围不再符合作者预期。单纯检查正文没有丢失或比较页可以打开，发现不了这些问题。

## 决定

在现有工作台里按作品、标签和文件保存临时编辑状态。返回时内容一致才接回撤销栈，关闭标签或切换作品释放；分屏移动不改变标签身份。阅读 / 编辑切换和单栏 / 双栏比较沿用这一规则。滚动现场使用编辑器的文档锚点，避免长文重新估算换行高度时只恢复像素位置造成偏移。

同一文件仍只共享一份草稿，不引入跨标签的全局撤销链。另一视图改过正文时不接回旧栈，避免撤销覆盖较新的内容。重载继续恢复现有持久草稿、光标与位置；撤销栈仅限当前窗口生命周期，不另存作品副本或新增持久协议。

单栏和双栏比较共用 100ms 的精细计算预算，替代默认的固定扫描长度限制，继续使用 CodeMirror 的差异算法及超时粗化。这是算法的检查预算，不是整个 UI 操作的硬性耗时上限；巨大且完全不同的文件仍可能出现较粗的差异块。验收必须核对分散修改数量、逐块还原范围、撤销和全文一致性，不能只数比较容器。

## 验证与限制

使用明确标注的合成长正文，分开记录输入、比较、切页和重载；不把规模 fixture 当成长篇文学作品。证据见[长正文验收](../validation/2026-10-14-long-editor/README.md)。保留同步草稿保护，没有为降低输入耗时增加延迟落盘窗口。
