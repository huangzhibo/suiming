# ADR-0016：按工作目的组织页面信息

- 日期：2026-10-10
- 状态：Amended；人物轨迹与文档引用默认折叠由 [ADR-0018](0018-character-experience-visibility.md) 取代，其余决定保留

## 背景

桌面现场审查发现：版本页重复身份和文件胶囊推迟比较内容；人物页先显示全书轨迹和事件，再显示人物介绍。共享属性容器不能据此对所有领域对象采用同一种折叠规则。

## 决定

版本页删除重复标题和解释口号，集中版本选择、可搜索的变更文件选择与只读差异导航，完整标识按需查看；恢复历史版本仍作用于整个作品。复用比较控件，但历史页不显示逐块还原。

人物页以别名和介绍开始，家族与明确记录的开场状态保留可见；全书引用轨迹移到介绍之后，以引用数和状态变化数作为展开入口。引用不能改称出场，开场状态不能改称当前状态。文档引用图与家族事实分开，默认按需展开。展开偏好只进入既有页面状态。

情节设计保留参与者、依赖、期待和本节变化的直接可见性。本轮不调整尚未充分走查的地点、资源、秘密、读者期待的业务布局。所有对象页无出入关系时不绘制空图。

## 后果与验证

共享比较导航、属性值渲染和设计 token；页面各自控制信息顺序，不新增领域模型、通用页面配置引擎或 Runtime 状态。通过真实 Electron 验证首屏几何、长篇人物介绍、轨迹展开恢复、文件搜索、差异导航、窄窗和只读边界，并在生产窗口复走。
