# ADR-0018：人物经历直接可读

- 日期：2026-10-12
- 状态：Accepted；取代 ADR-0016 中人物轨迹与文档引用默认折叠的决定

## 背景

作者在丁原页指出：只有短介绍和两个折叠入口，重要内容还要再次点击，页面可视化消失。此前只检查介绍位置和展开恢复，把布局通过误当成信息可用。少量事实的人物尤其受损。

## 决定

- 人物介绍、别名与已有结构属性直接展示，移除人物页字数；不把所有对象页套进同一种顺序。
- 情节引用与状态变化按故事顺序取并集，同一情节成为一个经历节点。即使没有人物引用，也展示它声明的死亡、位置或秘密变化。
- 经历用纵向连接线呈现，节点直接显示情节名称、顺序和变化，可打开原始情节；不依赖悬停或展开才能读到内容。
- 按卷分组，跨卷人物提供就地定位，所有卷内容常驻。少量记录不再缩成全书范围内挤在一起的点，也不添加无用导航。
- 经历已经涵盖的情节不再放进第二张引用图。其他关联文档直接列出；没有记录时明确说明。
- 引用不代表出场或人物关系；状态属于对应情节，不在页头宣称人物“当前”状态。保留共享故事轴投影，不另造领域状态。

## 后果与验收

移除两个折叠状态及其保存接线。测试改为保证少量记录首屏可见、无人物引用的死亡不遗漏、节点不重叠、来源可打开、密集人物跨卷可浏览，以及窄窗不溢出。真实桌面同时走查丁原与刘备；验收见[人物经历走查](../validation/2026-10-12-character-experience/README.md)。

## 2026-10-12 补充：信息可见之后仍需可辨识

作者继续指出灰色列表没有有效可视化、每行“引用”重复；选定的效果图增加蓝色卷带、蓝色普通节点与紫色秘密节点。本次沿用直接展示的决定，补充密集人物的全书分布，位置与死亡继续使用琥珀及红色，并配合形状与完整文字。稀疏人物省略概览，保持事实直接可读；概览只做分布摘要，不取代全部经历或来源导航。数据坐标、触发条件与多事件规则以[可视化设计](../visualization-design.md#43-人物页)为当前规范。走查证据见[人物可视化验收](../validation/2026-10-12-character-visualization/README.md)。

## 2026-10-12 补充：概览与目录承担真实定位

作者指出分布无悬停提示、宽屏空置、卷导航容易滚走。保留已选定的颜色、形状及单条时间线，补充概览预览与定位；所有节点仍直接可读。宽窗用余量放常驻卷目录，窄窗改吸顶选择器，不把连续经历拆成两份并排清单。目录跟随当前阅读位置，概览只有一个键盘入口，避免密集人物制造上百个 Tab 停靠点。验收补悬停内容、命中坐标、焦点、当前卷、遮挡和溢出，见[人物导航走查](../validation/2026-10-12-character-navigation/README.md)。

## 2026-10-12 补充：预览锚定实际标记

整条分布作为提示锚点会让首尾预览远离鼠标，还遮挡下方卷标题。保留单一键盘入口，另把选中标记作为定位锚点，提示优先向上并随边缘避让。位置验收增加锚点与箭头的几何断言；共享箭头交回 Base UI 计算，关系图节点按两侧向外提示。见[提示位置走查](../validation/2026-10-12-tooltip-placement/README.md)。

## 2026-10-13 补充：常驻目录覆盖完整阅读范围

页底的其他关联文档与阅读留白不应把卷目录顶出窗口。将它们纳入目录的 sticky 布局范围；目录按实际窗格高度收缩，超长列表内部滚动。保留 CSS sticky 与原有正文顺序，不引入全局 fixed 定位或为末卷强行补齐一屏空白。验收同时覆盖首端、末两卷、实际页底和宽窄窗，见[人物导航走查](../validation/2026-10-12-character-navigation/README.md#补充页底把目录向上推走2026-10-13)。

## 2026-10-13 补充：统一能力，按实际密度呈现

作者指出人物之间有无全书分布不一致。原先以 4 / 8 条记录为界，把分布当作长列表导航，忽略了单点也需要表达全书位置。改为有记录就显示紧凑分布，零记录只给明确说明；单卷省略卷导航，跨卷保留。模块顺序、全书坐标、语义色和交互一致；普通点位按分布带的实际像素间距统一呈现圆点或细刻度，不用孤立圆点暗示重要程度；混合的状态与普通记录在带内上下错开，状态图标和全部经历不隐藏。这样统一的是信息能力，差异化的是密度与实际导航需求。验收覆盖零记录、单点、少量聚集与密集跨卷人物。
