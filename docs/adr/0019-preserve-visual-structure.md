# ADR-0019：按对象补足可视化，保留关系结构

状态：Accepted，2026-10-13 补充期待路径。日期：2026-10-12。当前规范见[可视化设计](../visualization-design.md)第 4 节。

## 背景

地点、资源、情节页共用邻域图，但各自的问题不同。资源页缺少已声明的归属变化；地点页有单侧关联时仍留出空列；读者期待页把相邻锚点放在全书比例下，标题与期限挤在一起。

本轮首版把情节图换成两列文字，作者在使用中指出严重退步。该方案误把结构图当作属性的重复：信息逐项仍在，并不代表关联方向、对象中心与分类仍然容易理解。首版已撤销，未提交。

## 决定

1. 情节、地点与资源页保留当前对象、上下游节点、分类色和连线。不能以减行数、减少组件为理由换成普通清单。共享图只改排版与操作：按容器分配列宽，空方向不预留整列，长标题换行并增加节点高度。
2. 地点增加按卷的关联数量条形分布，条形使用同一标尺；不重复列出图内全部情节，也不推断地图或实际发生地。
3. 资源增加按作品顺序排列的流转记录，读取故事轴已有投影，标明开场归属和来源情节。未声明不补齐；该视图展示记录，不代替指定位置的状态查询。
4. 读者期待按建立、推进、回应显示全部锚点，保留期限和异常推进提示。全书跨度仍由故事轴表达；局部页优先让读者读清事件与来源。阶段色同时有图标和文字。
5. 验收同时检查信息、交互和图形结构。桌面测试守住节点、连线、分组展开、长标题几何与键盘导航；真实窗口截图用于判断布局，不把可点击或测试通过当作设计质量的充分证据。

## 后果

不增加领域字段、分析模型或第二份事实来源。不同对象保留各自的信息顺序，复用基础图形排版。极窄分屏允许图内滚动，不能把字号压小到不可读。大型关系组仍使用原有展开入口；修复了后面的分组可能误展开第一组的问题。验收与作者反馈见[走查记录](../validation/2026-10-12-object-visualization/README.md)。

## 补充：期待按实际事件连接（2026-10-13）

作者指出三阶段等宽卡片给零推进保留整列，事件间的过程又没有可视联系。经两轮效果图确认，期待页改用实际事件路径：按故事顺序组织，保留同节多阶段与回应后的异常推进；期限重合只标一次。少量记录有足够行宽时横排，密集或窄窗使用连续纵线，信息不随排版消失。

统一的是基础排版、语义色、图标尺度、来源导航与提示，不强制人物经历、情节关系图和期待路径使用同一张图。原文摘录复用已有文件读取和 Markdown 段落解析，不写新摘要或增加领域字段。省略期限与全书结束等价，状态投影与 Story Language 对齐。现场走查后收紧纵向节点的阶段/序号行，并放宽摘录行宽；记录见[验证报告](../validation/2026-10-13-contract-journey/README.md)。

## 补充：去重应保留用途与操作（2026-10-13）

继续走查时，资源开场归属在属性和流转重复，地点分布不能帮助定位，检查诊断反复附带相同长提示。决定分别处理：资源按情节归组而保留所有变化，地点条形联动原有关系图，检查只合并同文件逐字相同的处理建议，搜索仍匹配完整诊断。已提交审稿文件的阅读入口复用专用审稿组件，源文件编辑和候选边界不变。

去重以作者正在做的事为依据，不统一成同一种图，也不删掉承载关系结构的节点与连线。无新增领域模型或持久状态。证据见[页面走查](../validation/2026-10-13-page-polish/README.md)。
