# ADR-0022：大量版本共用可检索选择器

- 日期：2026-10-14
- 状态：接受

## 问题

版本页与比较基准平铺全部 revision，材料侧栏也被数百条历史挤满。当前 revision 投影只有 id / parentId；存储中的通用提交文案不能当成作品修改摘要。按日期或对话分组缺少可靠元数据。

## 决定

复用现有 Command / Popover，三个入口共用版本号与提交编号检索。支持 rN、纯数字和编号片段；纯数字只匹配版本号，避免随机编号片段制造噪声，精确版本优先，其余最近在前。稳定编号与 Canon 顺序一致，不因筛选倒序改变。

侧栏保留最近 10 条，有更多版本时提供全部历史入口；选择器保持全部结果可达，并标明命中量、最新版本和当前选择。关闭时卸载列表，重新打开清空临时查询。选择版本后保留文件与比较页原有导航语义；查询是找版本的临时动作，不新增全局搜索状态。

## 边界与代价

已知版本号的查找成为直接操作；不承诺能凭故事内容找回未知版本。后者需要可信的版本说明或变更内容检索，不能把一段通用提交文案包装成摘要，也不因此扩张领域身份。500 个结果仍使用现有列表，没有引入分页服务或虚拟化框架；更大规模应先实测。

验收覆盖 10 / 100 / 500 个版本、键盘、无结果、完整结果、窄窗定位和跨版本文件保持，见[规模操作验收](../validation/2026-10-14-version-and-conversation/README.md)。
