# ADR-0021：期待路径按空间换向，原文渐进披露

- 日期：2026-10-13
- 状态：接受

## 问题

原文摘录常驻使期待页过长，横纵布局的信息层级也不一致。只按节点个数换向，忽略分屏、侧栏及文档宽度限制，会出现宽窗仍纵排或窄窗强挤横排。作者在对比效果图后选定少量横排、多量或窄窗纵排。

## 决定

同一份事件内容保留阶段、全书序号、标题和必要异常。2 至 6 个节点、内容区至少 560px 且平均每节点至少 180px 时整条横排；其余用连续纵线。横排不折返、不缩字，路径最多 1260px，每节点分配不超过 280px。期待页允许使用这一宽度，不改变其他文档页宽度。

标题点击仍直接导航。图形节点与标题共用 Base UI PreviewCard：悬停或键盘聚焦预览，图形节点点击也可打开；Esc 关闭，移入卡片可阅读、选择原文并打开情节。预览贴着具体标题定位，横排优先下方，纵排优先右方，交给现有定位原语翻转和避让。换向时关闭旧预览。

原文摘录仅在打开预览时读取，复用文件查询与缓存，保留加载、空段落和重试反馈。不另生成摘要、不暗示摘录只属于该期待。去掉每页重复的「情节原文摘录」「无单独推进记录」说明；缺失建立、回应后推进等异常仍常驻。

## 边界与代价

不改期待的领域规则，不增加设置或用户模式。需要额外内容时多一步悬停，但浏览进展无需点击，原文页仍直接可达。稀疏路径与密集路径保留同一文字、颜色、图标、导航和预览；不把同一图形套到人物、资源等其他页面。

验证见[期待预览走查](../validation/2026-10-13-contract-preview/README.md)。
