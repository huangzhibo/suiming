# ADR-0031：外部文件变化不改变草稿归属

- 日期：2026-10-15
- 状态：接受

## 问题

作品目录允许作者和外部工具直接改动。打开的文件被删除或改名后，作品投影可能不再有它，但未保存的编辑仍有价值。若停止查询、展示旧缓存，或者丢掉编辑目标，就会让作者误以为文件仍在，或以为草稿已经丢失。

## 决定

草稿继续归属于原物理路径，使用现有共享 `documents` 与页面编辑目标保存；不新增文件身份表，不根据内容相似度追踪重命名。新路径作为独立文件打开。情节设计消失时，原页面仍持有其正文草稿的编辑目标，切页与读编切换不能把它换成缺失的设计路径。

普通保存仍核对原 hash，不能静默重建被删除的文件。作者可明确选择「恢复到原路径」，复用 `workspace.file.save` 和空基线 CAS：路径仍不存在才写入，后来出现的文件不被覆盖，结果只是 checkout 候选，不推进 Canon。辅助文件沿用同一条保存路径，不新增恢复命令；缺失文件的读取仍按原契约返回。

查询失败不把缓存显示为当前正文；有草稿时继续编辑，没草稿时展示缺失或读取错误。尚未创建的正文与外部删除区别显示。后台更新不抢焦点，主动返回编辑页和取消关闭恢复原编辑现场。

## 边界

不自动迁移引用，不推断新旧路径的领域身份，不新增备份格式或第二份作品真源。现有 Checker 继续检查重命名后的引用；草稿不属于 Canon，仍需保留原工作台的本机数据。当前规则见[工作台设计](../workbench-design.md)，验证与限制见[组合验收](../validation/2026-10-15-external-file-recovery/README.md)。
