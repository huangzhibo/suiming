# ADR-0032：文档外壳与状态反馈收敛

- 日期：2026-10-16
- 状态：接受

## 背景

外部文件恢复已验证草稿保全，但文档窗格同时叠加标签栏、导航栏、编辑操作行、失败横幅和恢复卡片。保存错误与文件状态分别显示，既重复又可能给出矛盾的处理方向。仅把卡片缩小或去掉背景不能解决职责重叠。

## 决定

沿用标签栏和一条文档工具栏。标签负责文档身份和未保存标记；工具栏承担导航、各页实际需要的视图与动作。保存进入该栏，放弃修改进入更多菜单；阅读 / 编辑切换保留草稿，不成为表单提交或取消。

文件异常以工具栏的可操作状态入口呈现。后台变化只改变入口，作者尝试保存受阻时才展开处理说明。删除恢复、外部冲突、格式诊断和读取失败按当前事实显示；同一次保存失败不再写入全局横幅。详情使用既有 Popover，保留键盘访问、Escape 返回与边缘避让。恢复仍通过现有 CAS 写入，不改变 Canon 或持久协议。

通用操作结果进入既有底部状态栏，完整信息按需展开；不增加内容区顶部的布局行。人物、情节、期待、版本比较等页面保留自己的内容结构和必要操作，统一的是外壳与反馈职责。

## 代价与边界

详情需要主动打开；可见的状态名称和保存受阻时的主动展开保证问题可发现，关键恢复后果在确认按钮旁直接说明。窄窗可以收起状态文字，但图标、可访问名称与提示必须保留。正常编辑不引入自动保存，不借视觉改造改变作者向共享 checkout 交出修改的时机。

不能只断言控件存在：验收必须测量输入前后内容位置、工具栏和弹层边界，并验证弹层关闭、切页、重载后的焦点与草稿。
