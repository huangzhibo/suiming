# ADR-0015：发送被拒绝时恢复可编辑草稿

- 日期：2026-10-08
- 状态：Accepted

## 背景

桌面走查中，没有模型配置的作者发送消息后进入「发送尚未确认」，模型菜单被锁住。Runtime 实际在创建 session / 入 inbox 之前就拒绝了请求，界面却把它与回包丢失放在同一个分支。

## 决定

首次发送返回明确的模型预检错误时，将本次文字与引用合回可编辑草稿，保留等待期间追加的内容，显示未发送原因并提供现有模型设置入口。错误码来自已有 CommandError；不增加消息协议、执行状态或第二条发送路径。

未知失败与回包丢失仍使用原 commandId 确认。确认重试期间出现的模型配置失败也不能证明此前未接收，因此不能自动退回或换一个 commandId。只有能够证明没有发送的分支可以解除冻结。

## 后果与验证

草稿恢复按提交 ID 核对，迟到失败不能覆盖另一条提交；所有输入继续保存在原工作区草稿中。保留原有回包丢失与幂等发送回归，增加真实 Electron 无配置发送、重载恢复和设置入口验收。现场证据见[桌面走查](../validation/2026-10-07-desktop-walkthrough/README.md)。
