# 作者盲读记录

日期：2026-09-06

阅读口径：按中文网文连载来读，主要看人物能否让我投入、场面有没有张力、读完想不想点下一章。以下两部分先于打开 sealed/ 写定；AI 味指文字的阅读感受。

## beat-0004

排序（最喜欢在前）：**D > B > A > C**。

各版一句话理由：

- A：关羽杀人后仍救不回周家的处境、田父知道旧案后不敢作保却仍肯送草，都有人情的复杂；但七日口粮、远途另备粮、救急粮如何开仓反复交代，连张飞都说出“只说这次具保、出粮和招募的事”，很像把审稿补丁直接塞进人物嘴里，越读越累，AI 味偏重。
- B：四版里吃饭拌嘴的生活气最足，张飞被管酒、关羽说“今日只到今日”、田豫留下补鞍，让我愿意看这几个人继续相处；但保责问答仍然太长，关羽用“敌手也不会挑同一日来”纠正誓言、制止折自家的桃枝，都有刻意讲道理和安排笑点的味道，AI 味中等。
- C：旁白太爱替人物认证，例如“没有一句哄人的漂亮词”“一句虚的没有”，又反复解释这笔账、这份约的分量，我还没来得及感动，作者已把感想念完了；旧案没讲清就无条件担保，前面许三百石粟、后面粮到后又说只够数日，也削弱可信度，四版中 AI 味最重。
- D：最像人物在现场碰撞，张飞会算马粮、会怕家业被拿走，刘备也会漏算，关羽一句“我不想再走”比大段解释更让我关心他；结尾木牍被抱进暗门，留下了不安和后续期待，AI 味相对最轻，但“替写清楚”仍像主题口号，以“长生”入册的风险也值得后文兑现。

有没有哪一版让你不想继续读？为什么：

**C 会让我弃读，A 会让我开始跳段。** C 篇幅最长，却不断用人物“看了半晌、终于认定”和旁白总结制造郑重感，事情本身没有相应的分量。A 有好场面，但同一套原则在招募、夜谈、次日核验中重复太多，桃树下该累积起来的信任，被责任范围和条件说明冲淡了。

D 最愿意追，B 也愿意。四版共同的问题是“账、簿、写清、谁来担”太密，仁义与结伴常常被写成逐项确认条款。算粮本身我爱看，尤其是它能让张飞拆穿刘备的疏漏；同一笔粮算完以后，再复述三遍用途，就不再推动故事了。结义可以克制，但仍要让我感到这三个人认定了彼此。

## beat-0005（Suiming）

愿不愿意让它留在书里？要改什么：

**愿意保留这一章的故事，现稿需要明显删改后再留。** 最抓我的是老宋来“领我闺女的名字”：救过女儿的人，转头拿死去女儿的名字征粮，委屈落到了具体的人身上。严石救弟弟却失去同袍信任，也有值得追下去的矛盾。相比之下，张角病死本该让我难过，现稿却更像临终反复交代制度，悲凉被说明挤走了。整体 AI 味偏重。

- 删重复讲理。保留老宋讨名字的冲突、一次分册决定和一次焚册交接即可；“记病不记债、受救不传召”、总网与分路的利弊，被张角、杜蘅和旁白轮流复述，后半章多次像已经收尾，又继续总结。死亡处那碗凉水可以留，前后的生平与价值总结宜删。
- 理顺严石的选择。他说“我不回了”，随即又回北门，却缺少促成改意的动作或信息。救人时的急迫感和回来时同袍的冷脸足以让我懂代价；阿弟、周军士、旁白再逐一说明信用受损，显得所有人都知道自己在论证什么。“走过青州，走过屯田管车牛的岁月”还提前讲掉了本可留到后文发生的后果。
- 校准撤离时间与路线。病者车队先被安排最后，后文却说杜蘅带头一批；严石线写天明后广宗起火、回顾那夜南门破城，张角线末尾又写第二日夜里破城。至少把批次、守门结束、张角死亡和破城的先后排清，让读者看得懂人物为什么来得及走或回不去。
- 张角说“不应的人，锅里少他那一份便是”容易读成不出粮就不给饭，和前文不以救治索债的坚持打架。应说清是总粮少了一份，还是取消某人的救济；同时让自愿筹粮后的缺口真正影响分粮或撤离，不能一句“另问”就把困境解掉。

## 看完 sealed/ 之后

Suiming Reviewer 的 6 条 finding，哪些你认可、哪些不认可：

1. **认可，补一个动作即可。** C 把代役写进正簿之后，刘备却能自行跑县寺、另募队伍，确实缺了义务如何转接的交代。获批时顺手将原代役牍并入本队，便足以回应前文；不需要再加一轮手续解释。
2. **认可，优先改。** 杜蘅车队到底先走还是殿后，会直接影响严石为何离岗、为何来得及救人。阿弟自行挤进第三批本身可以成立，但要交代他为什么离开病者车队；“头一批”和“排在最后”则需要统一。
3. **强烈认可，而且不只是结尾。** 这是 C 最重的 AI 味来源之一：人物刚表态，旁白立刻解说他真正要什么，结尾再把“账”总结几遍。应删掉重复释义，让署名、收册、人物反应承担收束。
4. **强烈认可。** 不在于超过了几个场面的规定，而在于后来的场面没有增加新的冲突，持续证明刘备会照顾家属。留一户确实解决了难处的，再留一户因此仍不能入队的，其他简短带过，比连演多次成功说服更有层次。
5. **不认可把“恢复雨夜死亡”列为必改。** 单看正文，雨停后悄然死去也可以成立；“日头偏西才发现”也不能直接当成准确的死亡时刻。我在意的是整章死亡、撤离与破城的先后能否看懂，以及临终有没有情感力量。若作者确实要保留雨夜意象，可以改，但不能仅以不符 Design 判它读着不好。
6. **部分认可，低优先级补清。** 老汉的孙女和她娘为何在院里守门、与受保护的县吏家小是什么关系，确实有点绕；补一句她们在帮着照料产妇或守院即可。“我不认得什么吏”则可以读成不论身份的口气，不一定是在声称自己不知道对方身份，不必为此添一段身世。

Reviewer 抓到了重复和连续性问题，但 **“全部 minor / note”的轻重不符合我的阅读感受**：第 3、4 条已经到了让我想弃读的程度。它对 beat-0005 的反复说理、严石“我不回了”后又回去、提前总结一生后果，以及“不应的人”是否断粮的歧义，也抓得不够。我的修订顺序是先恢复场面推进和情绪，再校准因果与时间，最后补必要的簿册交接。

对四条创作路径的印象和以前一样吗：

没有此前四条路径的阅读记录可对照，不能声称印象变了或没变。**揭晓来源后，本轮排序不变：新仓 Claude Code（D）> 旧仓 Codex（B）> 新仓 Codex（A）> 新仓 Suiming Agent（C）。**

这次新旧 Codex 使用同一 Writer 型号，但我更喜欢旧版 B：生活互动更多，条件说明没有 A 那么挤。D 最让我相信三个人各有脾气、局限和欲望；Suiming 两篇都有可用的故事矛盾，尤其是老宋那一场，却常被反复说明主题拖住。就这批成稿而言，设定与责任交代得更全，没有自动换来更好的追读体验。下一轮我会优先看人物是否更鲜活、重复是否减少，而不是先看创作路径的名字。
