第一次的读法：评委与作者都把 Suiming 版排最后、理由类别一致（旁白作证、复述、搬 Design 句），说明它抓"差"是准的；它把作者最喜欢的 D 排第三（嫌关羽自述长、中段发闷），把 A 与 B 抬高，说明它对"人物是否鲜活"的判断还跟作者不一致，且两轮之间 A 从第 1 掉到第 3，位置偏差明显。结论：可以用来淘汰明显差的版本，不能用来在好版本之间替作者做选择；一致率要靠后续记录累积。第二轮重写的两组各三版里，评委都没有把重写版排在第一轮原稿之后（beat-0004 原稿明确垫底，beat-0005 三版打平），与契约已改、篇幅短了三成的预期一致；但 V4 Pro 版在两组里都出现 1 → 3 的名次跳动，评委给 flash 版仍点名关羽内心自述是替人物作证式的旁白，说明契约只是减少、没有消灭这类句子。评委细评留在盲读包的 `sealed/` 目录里，没有入库。eval-022 暂停后这两组重写稿不再安排第二轮盲读；以后每次作者盲读或抽查，评委一致率仍记在上表。
